# Changelog

All notable changes to the DFT Handbook are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- DFT Studio at `/dft-studio/`: a VESTA-style 3D crystal viewer and editor with the VASP workflow (POTCAR, INCAR, KPOINTS, k-point convergence, run bundle, analysis). It is now the Material Builder crystal mode, runs the site structure checks live, and hands structures and results to and from the Input Builder, k-path, magnetic and convergence tools (D-103).
- Calm app layout: a left sidebar with icon navigation, search, reading level, progress and theme on wide screens, a top bar and drawer on phones, and a warm palette with one accent (D-104).
- Tests for the Material Builder: crystal templates, molecule export, and an end-to-end keyboard and axe spec at 360 px (M15.3).

### Fixed

- Guided path figures are no longer solid black: the plot styles now load on `/learn/`, labels no longer collide, and 3D stations use an angled camera.
- Buttons, text fields, menus and file pickers on the labs, 3D scenes, periodic table and tools pages have the site look instead of browser grey.
- No sideways scroll at 360 px on the k-path, EOS and progress pages or in open equation sections; React hydration error 418 on handbook, practice and progress pages.
- Deploy runs only after CI succeeds on main (D-089).
- Crystal and molecule builder, and the Input Builder Task step, no longer overflow the page at 360 px wide.
- Tolerance-factor element buttons now start their accessible name with the visible symbol (axe `label-content-name-mismatch`).
- End-to-end specs wait for island hydration before typing or using the keyboard; the landing page spec expects the 12 starting points the page now has.

### Changed

- Heisenberg fit default convention is now H = E0 - sum J S_i.S_j, pairs once, unit spins (J > 0 ferromagnetic), as in the Workflow Handbook and the textbooks (Q-042 closed, D-087). The plus sign is still available.

### Added

- Magnetic tool, Analyse tab: Heuristic classical mean-field Curie temperature for a ferromagnetic ground state, k_B T_C = (2/3)(E0 - E_FM) per magnetic ion (S-070), with its known overestimate (S-071); D-087.
- Release preparation (`M11.3`): updated top navigation so Studio (`/studio/`) and Builder (`/builder/`) point directly to live routes, updated `/about/` limits and `README.md`, added a Release Triage section to `docs/OPEN_QUESTIONS.md`, wrote `docs/AUDIT_PACKAGE.md`, and prepared the unmerged `chore/enable-indexing` branch for post-audit launch.
- Accessibility and security audit (`M11.2`): added Content Security Policy headers in `firebase.json` (with `'wasm-unsafe-eval'` and `worker-src 'self' blob:`), switched `lighthouserc.json` assertions to `"error"`, and added `tests/e2e/a11y-csp.spec.ts` covering axe checks, 360 px overflow, and zero CSP violations.
- Performance and offline audit (`M11.1`): documented all 102 routes against `budgets.json` and lazy-chunk limits in `docs/reports/M11.1.md`, with conservative 360 MB/day Spark transfer estimates recorded in `Q-006`.
- Modules 10 and 11 (`M7.6`): six worked-example topics for `RCuO3` perovskites (explicitly flagged "Results pending: author data not yet supplied" until `data/author/` is populated per `Q-008`), four Screening Studio and Material Builder tour topics, 6 published concepts, and 24 visual practice questions.
- Research Planner (`/tools/planner/`, `M14.2`): goal-to-workflow generator covering all 11 DFT calculation goals with sourced recipes (`src/data/recipes.json`, guarded by `scripts/guard/check-recipes.mjs`), surface-slab helpers, and downloadable project zip archives.
- Material Builder (`/builder/`, `M10.4` and `M10.5`): crystal editor UI (symmetrization, supercells, slabs, defects, validity checks, undo/redo, POSCAR/CIF/XYZ export) and lazy-loaded Molecule Builder (2D RDKit canvas with keyboard fallback, 3D valence clean-up, XYZ/MOL/POSCAR-in-box export).
- Screening Studio (`/studio/`, `M9.2` to `M9.4`): Materials Project dataset explorer with periodic-table filter, feasibility checker, first-project generator, offline/attribution banners, and synthetic demo guard on live deploys.
- Charge-density and spin-density tool (`/tools/density/`, `M14.3`): browser-side CHGCAR/PARCHG difference, spin density, and planar-average visualizer.
- Module 9: Analysis (`M7.5`) and Calculation Review (`/tools/review/`, `M14.1`): analysis handbook topics with relaxation, DOS/band, and charge-density tools, plus pre-flight and post-flight VASP calculation checks.
- Tolerance Factor Explorer (`/tools/tolerance/`, `M8.3` and `M8.4`): interactive Goldschmidt `t`, octahedral `mu`, and Bartel `tau` explorer with shared periodic table, 2D formability maps, lanthanide family trends, and tool hand-offs.
- Spin-polarized DFT and magnetism handbook module (`M13.4`): visual guide to collinear magnetic orderings, `MAGMOM`, and exchange mapping.
- Analyse tab in the magnetic configuration tool: after running the orderings, give each one its OSZICAR or OUTCAR (or type its energy) and see the orderings ranked by energy per magnetic ion relative to FM, with a bar chart, the final moment on every magnetic site next to its starting MAGMOM and a heuristic "pattern kept" check, and an optional fit of exchange constants J1 to J3. The Hamiltonian convention (sign, each pair once or twice, unit spins or spin S) is chosen by you and printed next to every J. Files are read in your browser and never uploaded; no Néel or Curie temperature is estimated.
- Guided path at `/learn/`: fourteen short stations from one atom to your first VASP folder (electron cloud, orbitals, the exponential wall, density, the Kohn-Sham idea, the SCF loop, the unit cell, periodic images, plane waves, reciprocal space, k-points, bands, spin orderings, the four input files). Each has one picture marked computed, toy model or illustrative, three plain sentences, one thing to try and a link to the full topic. Move with the buttons or the arrow keys; 3D loads only when you press "View in 3D". There is a new Learn link in the header.
- Optional progress sync (only on builds with Firebase configured): sign in with Google on the progress page to merge your practice progress across devices. Off by default, the sync code is not downloaded until you press the button, writes are at most one a minute, and a "Delete my synced data" button removes the cloud copy. The privacy page explains what is stored.
- Module 8: six topics on convergence testing (what converges, ENCUT, the k-mesh and smearing) and on common failures (SCF trouble, relaxation trouble, reading error messages), 24 practice questions with pictures, and one new question picture for convergence series.
- Error finder at `/errors/` and inside the common-errors topic: paste a VASP log excerpt or describe a symptom and get likely causes and fixes in order, matched in your browser (33 entries from the Field Handbook and the Workflow Handbook; nothing is uploaded).
- Modules 6 and 7: ten topics on the VASP files (POSCAR, KPOINTS, INCAR, POTCAR structure, the sixteen output files) and on running a calculation (the author's five-step protocol quoted as written and the project folder, SLURM and PBS job scripts with NCORE and KPAR, ISTART and ICHARG restarts, reading OSZICAR and OUTCAR, VASPKIT command map). The POTCAR topic never shows contents. 40 practice questions with pictures and 14 glossary terms.
- Output reader lab: choose a sample, paste text or pick an OSZICAR or OUTCAR file (read in your browser, never uploaded) and see whether each electronic loop and the ionic loop converged against your EDIFF, EDIFFG and NELM, with every line explained. The built-in samples are synthetic and marked so.
- "Show me" on INCAR tag cards: ISPIN, MAGMOM, ENCUT, KSPACING, ISMEAR, SIGMA, LDAUU, LDAUJ, IBRION, ISIF, NSW, EDIFF, EDIFFG and NELM now have a small picture of what the tag changes, in the Input Builder, the file explorer and four handbook topics. The picture follows the value you type, uses your own structure when one is loaded, and says when it is a toy or only an illustration. Nothing loads until you press "Show me".
- Module 5, first half: four topics (plane waves and ENCUT, k-points and the Brillouin zone, smearing and the Fermi level, DFT+U), 34 practice questions with pictures, and two new labs: smearing (five schemes, a clearly labelled toy metal, the entropy term) and the Dudarev DFT+U penalty. Then the second half: pseudopotentials and PAW, the functional ladder, spin and magnetism, and van der Waals corrections, with three labs (a schematic PAW picture, the functional ladder, a spin cartoon) and 24 more questions.
- Practice and progress. The questions at the end of each topic now work: they come one at a time, you can ask for a hint or say "I am not sure", and every option is explained afterwards. The new Practice page picks short sessions (up to 10 questions) and brings questions back when they are due, and tells you why it chose each one. The new Progress page shows a map of every idea (open circle, hatched diamond or solid square for not started, learning and mastered), the same map as a list, a practice run that forgives a rest day each week (you can hide it), milestones, and buttons to export, import or erase your data. No timers, no ranking, no sign-in; everything stays in your browser.
- A structure view beside every POSCAR the site shows: in the file explorer, the Input builder (with MAGMOM arrows) and the k-path tool. Turn on Measure mode and pick two, three or four atoms (by mouse or keyboard) to read a distance, an angle or a dihedral, across cell boundaries. Pick one atom to see its coordination. Clicking a coordinate line in the file explorer highlights that atom and the reverse.
- Magnetic configuration tool at `/tools/magnetic/`: paste a cell, pick a ferromagnetic, A, C, G, rock-salt II, custom or enumerated ordering, see the up and down arrows (and coordination polyhedra) in the cell, and download POSCAR, MAGMOM and INCAR files for each ordering, one folder per ordering in a zip. All orderings share one cell by default so their energies are comparable. You type the starting moments and any U values yourself; the tool suggests none. It can send the structure and MAGMOM to the Input builder.
- Scene library: any page can now show a 3D picture of a crystal (atoms, bonds, coordination octahedra, spin arrows, planes, lattice vectors) from a few lines of data. It starts as a flat picture, turns with the arrow keys, and loads real 3D only when you press "View in 3D". Fourteen presets, including sc, bcc, fcc, hcp, rock salt, perovskite and four magnetic orderings (marked as toy models).

- Screening Studio data pipeline (no UI yet): scripts that fetch a filtered Materials Project snapshot with the author's own API key, then turn it into a compact filter index and on-demand structure shards with hashes, size budgets and a strict schema checked in both Python and the browser. Synthetic demo data are included for development and are clearly marked. The live site refuses to deploy them.
- Equation-of-state tool (`/tools/eos/`): drop the OUTCAR of each volume, or paste a table, and fit Birch-Murnaghan or Murnaghan. You get the equilibrium volume, bulk modulus (GPa and eV/Å³), B0', the lattice constant for cubic cells, each with its fit error and unit, a residual plot, plain warnings when the sampling or the noise is poor, and SVG, PNG and CSV export. The Input Builder's series step can now write the matching energy-volume scan (one fixed-volume folder per volume, ISIF = 4 or 2 for cubic cells, with the reasons in the README).
- Molecule engine (check page only, the editor comes later): read SMILES or MOL files with RDKit, which is downloaded only when you first use molecule work. You get a plain explanation when an atom has too many bonds, a tidy 2D drawing, and a rough 3D starting geometry, clearly labelled as one, with export to XYZ, MOL and a POSCAR with the molecule in a vacuum box (Gamma-only and ISIF = 2 advice included).
- Structure toolkit (no UI yet): surface slabs for any (hkl) with the shortest in-plane cell, every distinct termination, thickness, vacuum, centring, fixed bottom layers, and heuristic flags for symmetric and polar slabs (with the dipole-correction advice); symmetry-distinct sites, vacancies, substitutions, defect pairs grouped by symmetry, the smallest supercell that keeps a defect 10 Angstrom from its images, and the neutral defect formation energy. Checked against pymatgen and spglib.
- Crystal operations (no UI yet): symmetrize a noisy structure while keeping your cell and orientation, snap atoms to Wyckoff positions, switch to the primitive or conventional standard cell, wrap, merge duplicates, build supercells, set new lattice vectors and a gentle geometric clean-up of clashing atoms (clearly not a physical relaxation). Every step says what it changed and can be undone and redone. Export to POSCAR, CIF (P1 or with symmetry) and extended XYZ.
- Structure checks (no UI yet): element data up to Z = 103, and a rule engine that flags overlapping atoms, short contacts, impossibly dense or squashed cells, charge imbalance (with rare oxidation states named), Pauling's first and second rules, the perovskite tolerance factor, Hume-Rothery limits for alloys, duplicate atoms across cell faces and the symmetry summary. Every concern explains why, links to the lesson, and offers a one-click fix where one exists; errors block export unless you give a reason, which is written into the file.
- Tolerance factors: Goldschmidt t, the octahedral factor and Bartel's tau (now checked against the paper), with mixed A and B sites, charge balance, oxidation-state frequency warnings from ICSD counts, and rule-of-thumb range notes that are labelled as such (no UI yet).
- New look: warm neutral surfaces, one clay accent, monospace interface text, bracketed tags such as `[computed]` and `[toy model]`, a landing page that is a single prompt line plus starting points, and a status line (level, theme, modules done, network). Press Ctrl+K, Cmd+K or `/` for a command palette that reaches every page, tool, handbook topic, INCAR tag and glossary term; `/theme dark`, `/level pro` and `/kpath` style shortcuts work too. The palette loads only when first opened.
- Shannon radii: the full table of ionic and crystal radii (492 entries, 94 elements) with a lookup that tells you why a radius is missing, or that a spin state must be chosen, instead of quietly substituting a nearby value (no UI yet).
- Module 4, Hohenberg-Kohn, Kohn-Sham and the SCF loop: five topics, 33 practice questions and 7 glossary terms, with a self-consistency lab (a one-dimensional two-electron toy model, clearly labelled) where you play the loop iteration by iteration, change the mixing and watch it converge, crawl or oscillate.
- Magnetism library: supercells from any integer matrix, ferromagnetic, A-, C-, G-type and rock-salt type II orderings, one common cell for comparing orderings, enumeration of distinct spin arrangements, and MAGMOM in POSCAR order (no UI yet).
- Practice policy: a Thompson-sampling helper with fixed guard rails that picks the next practice action, a seeded simulator for testing it, and the plain-language "How this works" text (no UI yet).
- Learning models: Bayesian knowledge tracing, an Elo/IRT difficulty estimate, SM-2 spaced repetition and a mergeable learner state (no UI yet).
- Concept graph (73 concepts with prerequisites) and a validated question bank with a grader, plus a content lint that requires at least 4 questions per concept; module 1 now has 40 questions and every question has two hints.
- k-path tool at /tools/kpath/: choose one of the 14 Bravais lattices or drop a POSCAR or CIF, see what standardizing did to your cell, switch between the HPKOT and Setyawan-Curtarolo paths, set points per segment or a density, watch a marker move along the path in the Brillouin zone, and download KPOINTS (line mode), KPATH.in, KPOINTS_OPT, a CSV or JSON point list and the standardized POSCAR. The Input Builder can hand its structure over.
- 3D Brillouin zone viewer and unit cell viewer: translucent zone with labelled reciprocal vectors, special points, the k-path with direction ticks and an optional k-mesh; real-space cells with atoms sized by covalent radius, colour-blind-safe element colours, bonds and 1 to 3 repeats. Orbit, zoom, pan, preset views and keyboard control; a flat rotatable view with dashed hidden edges when WebGL is missing. Pages at /design/brillouin-lab/ and /design/unit-cell-lab/.
- Second band-path convention (Setyawan-Curtarolo, the one pymatgen and the Materials Project use): all 23 lattice variants, selectable alongside the default HPKOT path (no UI yet).
- Recommended band path (HPKOT convention, the one SeeK-path uses): the special points, their coordinates and the path for any structure, for all 29 lattice variants, with a warning when a cell sits on the boundary between two variants (no UI yet).
- Brillouin zone geometry library: the exact first Brillouin zone (vertices, edges, faces, volume) for any lattice, checked against an independent Voronoi reference (no UI yet).
- Symmetry and structure files: find the space group of a POSCAR, CIF or XYZ file in your browser (the engine loads only when you ask), see what standardizing the cell changed in plain language with the transformation matrix, and read CIF files safely (partly filled sites are refused with an explanation). Check page at /design/symmetry-check/.
- k-point mesh lab: Monkhorst-Pack and Gamma-centred meshes drawn in the reciprocal cell, the number of irreducible points under the lattice symmetry, a plain explanation when a mesh breaks the symmetry, and a toy panel showing why metals need denser meshes than insulators.
- ENCUT lab: pick a cell and a cutoff, see the sphere of plane waves with the exact count next to the smooth estimate, a scaling hint, and a toy-model curve showing why a higher cutoff changes the energy (3D view loads on request; flat slice without WebGL).
- Convergence plotter tool: drop OSZICAR or OUTCAR files or paste a table, see where the energy stops changing with a threshold band and a plain-language explanation, and export SVG, PNG or CSV. Runs in your browser.
- Convergence series generator in the Input Builder: ENCUT and k-mesh test folders with INCAR, KPOINTS, POSCAR and job scripts, plus run, collect and POTCAR-assembly scripts, downloaded as one zip (never contains POTCAR content).
- Output readers and convergence check library: OSZICAR, OUTCAR and pasted series, with the rule that a setting counts as converged only when every later point stays within the threshold (no UI yet).
- File explorer for handbook pages: click any line of a POSCAR, KPOINTS or INCAR to read what it means at your level, plus a panel describing the fields in a POTCAR header (structure only, no POTCAR content).
- Input builder tool: paste a POSCAR, pick a task, edit and check an INCAR with plain-language explanations, choose k-points, write a SLURM or PBS job script, and download a zip of the input files (never a POTCAR). Runs in your browser; nothing is uploaded.
- INCAR validation engine: 33 sourced rules that catch risky settings, with one-click fixes (no UI yet).
- INCAR library and data: parser and writer, 71 documented tags and 16 starting presets built from the two handbooks (no UI yet).
- KPOINTS library: k-mesh sizes from KSPACING, resolution or length, mesh coordinates, file writers and a parser (no UI yet).
- Structure core library: lattice math, POSCAR reader and writer, composition and density helpers, and the tool hand-off store (no UI yet).
- Site shell: header with navigation, search, level switch, progress tracker and theme toggle, plus a footer
  and a keyboard-shortcut list.
- Landing page, handbook module map, About, Privacy and Tools pages.
- Reading progress saved on your device only, with a reset button.
- Handbook pages now have a sidebar, breadcrumbs, previous and next links and a "Mark complete" button.
- Module 1, "Why DFT exists": four topics, an interactive lab on how the cost of methods grows with system size, practice questions and 14 new glossary terms (all draft).
- Module 2, "Quantum basics without math": six topics, two interactive labs (a particle in a box and hydrogen orbitals as a 3D point cloud with a flat fallback), practice questions and 9 new glossary terms (all draft).
- Module 3, "The many-electron problem": five topics, two interactive labs (counting the exponential wall, and a density-to-potential map with N non-interacting electrons), practice questions and 6 new glossary terms (all draft).
- Every practice question now shows a picture (a crystal, a plot or a diagram) with a caption and a text description. Crystals can be opened in 3D. A few questions about using the site have none.
- Design system, content system and one sample topic (draft).
