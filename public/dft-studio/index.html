          Antiferromagnetic Ordering Theory & Automatic NN Logic (VASP)
        

        
      

      

        

          Magnetic ground-state screening in DFT/VASP compares total energies across the canonical Wollan–Koehler (1955) spin configurations and Goodenough–Kanamori–Anderson (GKA) superexchange rules. This studio automatically inspects the periodic nearest-neighbor (NN) bond graph of magnetic ions to assign each ordering without manual index calculation.
        


        

          

            
FM: FerromagneticJ∥ > 0, J⊥ > 0

            
All magnetic ions align parallel (↑↑) both in-plane and out-of-plane. Typical in metallic ferromagnets (BCC Fe, Co, Ni) or double-exchange perovskites (La1−xSrxMnO3).

            
Logic: All magnetic sites → +m

          


          

            
AFM-A: Layered A-TypeJ∥ > 0, J⊥ < 0

            
Ferromagnetic within each basal ab-plane, antiferromagnetic between adjacent planes along c. Classic in Jahn–Teller LaMnO3 and layered vdW magnets (MnBi2Te4, CrI3 bilayer).

            
Logic: Cluster z-planes → alternate (+, −) along c

          


          

            
AFM-C: Chain / Columnar C-TypeJ∥ < 0, J⊥ > 0

            
Antiferromagnetic checkerboard within each ab-plane, ferromagnetic along chains parallel to c. Observed in orbital-ordered vanadates/chromates (LaVO3, CaCrO3, Sr1−xCaxMnO3).

            
Logic: 2D BFS 2-coloring on in-plane NN graph; same spin along c-columns

          


          

            
AFM-G: 3D Néel G-TypeJ∥ < 0, J⊥ < 0

            
Every 3D nearest-neighbor magnetic pair is antiparallel (↑↓ in both ab and c). Driven by strong 180° M–O–M superexchange in half-filled shells (LaFeO3, BiFeO3, CaMnO3, LaCrO3).

            
Logic: Full 3D BFS bipartite 2-coloring on PBC 1st-NN shell (d_NN)

          

        


        

          
AFM-II: Type-II Rocksalt (180° 2nd-NN Superexchange)J₂ < 0 (FCC)

          
In FCC rocksalt oxides (NiO, MnO, CoO, FeO), the 1st-NN metal sublattice forms edge-sharing triangles (geometrically frustrated for 1st-NN AFM). Instead, 180° M–O–M superexchange couples 2nd-NN sites along ⟨100⟩, creating FM {111} sheets stacked antiferromagnetically along [111].

          
Logic: Alternate spin by {111} plane parity / 2nd-NN superexchange shell

        


        

          Key References: E. O. Wollan & W. C. Koehler, Phys. Rev. 100, 545 (1955); J. B. Goodenough, Phys. Rev. 100, 564 (1955); J. Kanamori, J. Phys. Chem. Solids 10, 87 (1959).
