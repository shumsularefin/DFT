# Science sources register

Every formula, constant and data table in the code, and every factual claim in the content, points here with an ID such as `S-003` (in a `@source` comment, in MDX front matter `sources: [S-003]`, or in `<Cite id="S-003" />`). `node scripts/guard/run-all.mjs --only sources` fails if an ID is used but not defined. The public References page is generated from this file (M1.2).

**Status values.** `cited-from-memory`: the citation was written from memory and has not been checked against the publisher or DOI page. `cross-checked`: the numbers or formulas agree with an independent implementation or golden file (name given). `read`: a builder or the author read the source and confirmed the specific use. Nothing is `read` yet. Upgrade a status only after doing the work, and say what was checked in the Notes column.
