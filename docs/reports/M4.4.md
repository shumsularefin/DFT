# M4.4 ENCUT lab and toy plane-wave solver

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `src/lib/physics/planewaves.ts`: exact plane-wave counts for any cell and ENCUT, continuum estimate, cutoff radius, guards for huge cells. All 20 golden counts in `tests/reference/pw_kmesh_reference.json` match (fcc Cu: 181 at 400 eV vs 213.7 estimate, 331 at 520 eV).
- `src/lib/physics/kp1d.ts` (+ worker `kp1d.worker.ts`, client `kp1d-client.ts`): 1D toy plane-wave solver (cosine and Kronig-Penney potentials, Jacobi eigensolver), convergence curve off the main thread.
- `src/lib/three/EncutScene.ts`: points inside a translucent cutoff sphere with the reciprocal cell wireframe; lazy loaded.
- `src/components/labs/EncutLab.tsx` registered as lab id `encut-sphere` in `Lab.astro`; demo page `/design/encut-lab/`. Cell chooser (sc, fcc, bcc, hex, own POSCAR), ENCUT slider plus number input, readouts, exact-versus-estimate message, scaling hint labelled as not a runtime prediction, flat 2D slice fallback, toy curve with the Toy model badge reusing the convergence plot and `analyzeSeries`.
