## Solver timing (task 2)
Node, 8 states, mean of 5 runs after warm-up: 6.3 ms at 1200 points, 13.9 ms at 2000 points. That is far below a frame, so the solver runs on the main thread and no worker was added; the lab stays responsive (e2e drags and keyboard changes re-solve instantly). Not measured on a phone.

## Bug found by the tests
The lab first printed the raw round-trip mismatch (about 6e-14). Rounding noise differs between Node (build) and Chromium, so the server and browser text differed and React raised hydration error 418, which re-created the DOM and broke pointer drag. The lab now prints "below 1e-6" (D-033).
