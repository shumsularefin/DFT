## What was built
- **`src/lib/history.ts`:** an immutable undo/redo stack with a size cap.
  - Functions: `createHistory`, `push` (which discards redo), `undo`, `redo`, `canUndo`, `canRedo`, `undoLabel`, `redoLabel`.
  - Each entry stores a state and the description of the step.
- **`src/lib/crystal/ops.ts`:** every operation returns `{ structure, description, changed, notes }`.
  - `symmetrize(api, s, symprec = 0.01)`
  - `snapToWyckoff`
  - `standardizePrimitive` (uses the M5.1 standardization report text)
  - `standardizeConventional`
  - `wrap`
  - `mergeDuplicates(s, tol)`
  - `supercellOp(s, M)`: the work order calls this `supercell(matrix)`. The name `supercell` is the M13.1 re-export (a plain structure), so the description-returning wrapper needed another name. There is no second implementation.
  - `setLattice(s, L, 'fractional' | 'cartesian')`
  - `gentleRelax(s)`
  - The moyo operations take the module as an argument, the same way `analyzeWith` does.
- **`deleteSites` moved to `crystal/structure.ts`.** The M10.1 fixes `deleteAtoms` and `mergeDuplicates` now delegate to it and to `ops.mergeDuplicates`, so each exists once.
- **Exporters (`src/lib/crystal/export.ts`, plus `writeCifWithSymmetry` and `formatSymopComponent` in `cif.ts`):**
  - POSCAR uses the M3.1 writer and notes when atoms were regrouped.
  - CIF in P1.
  - CIF with symmetry: moyo's conventional cell, its operations written as `-x+y+1/2` style text, and one atom per orbit.
  - Extended XYZ: `Lattice="..." Properties=species:S:1:pos:R:3 pbc="T T T"`.

What the tests check:
- **moyo conventions:** an ideal NaCl cell, rotated by 30 degrees, sheared (a2 = a1 + a2) and shifted by (0.1, 0.2, 0.3), symmetrizes back to itself within 1e-10, with `changed: false`. This shows the mapping and that moyo's rotation is not applied.
- **Perturbed NaCl (work order):** every atom is moved 0.01 Angstrom in a seeded random direction (mulberry32, seed 42). Before: not 225 at symprec 1e-4. After `symmetrize`: 225 at symprec 1e-6. Positions equal the ideal ones within 1e-6 up to one common translation (below 0.01 Angstrom; any origin is equally ideal), and the lattice is unchanged within 1e-9.
- **Strained cell:** comes back with a = b = c and 90 degree angles, and L^-1 L' is symmetric (pure strain, no rotation).
- **fcc Cu (work order):** the conventional cell from `kpaths.json` gives 1 atom with the metric of the golden HPKOT primitive cell (1e-9), then 4 atoms back with V = 3.61^3.
- **Round trips (work order):** NaCl, SrTiO3, triclinic P-1, alpha-Al2O3 and graphite each go through POSCAR, CIF P1 and extended XYZ and come back within 1e-8, read with `readStructure`. The CIF with symmetry expands to the same conventional cell (as a set, within 1e-8, and the same lattice parameters).
- **Undo/redo (work order):** 5 operations (wrap, supercell, merge, set lattice, clean-up) undone and redone return the identical state objects, and nothing is mutated. The tests also check the cap and that redo is discarded after a new push.
- **gentleRelax:**
  - a B001 pair is cleared and the third atom does not move;
  - one step moves at most 0.05 Angstrom, and a run never exceeds 200 steps;
  - frozen atoms stay put;
  - coincident atoms are reported;
  - a clean structure is unchanged.
- **Symmetry operations:** written text parses back to the same rotation and translation.
