## What was built
- `src/styles/tokens.css`: warm light and dark colour blocks, clay accent, radius 6/8 px, shadows 1 px. Selectors unchanged, `npm run contrast` passes (lowest text pair 5.9:1 on the accent, UI pairs at least 3.9:1). New `src/styles/interface.css`: mono interface face, panels, step list and busy-indicator idioms (U+25CF, U+23BF, with text equivalents), landing session, palette styles.
- Badges are bracketed mono tags (`[computed]`, `[toy model]`, `[illustrative]`, `[heuristic]`), still with their shape icons. Stepper uses the filled-circle marker and a screen-reader "Step n" prefix.
- `src/lib/commands.ts` (pure): registry type, ranking (tiers: exact, title prefix, title word start, keyword start, title substring, keyword substring; ties by group order, title length, registry order), slash aliases and `/level`, `/theme`. `scripts/build/build-commands.mjs` writes `public/data/commands/commands.v1.json` (168 commands, 5.6 KB gzipped; gitignored, built by `npm run build` and `predev`). It fails the build if a listed route has no page.
- `src/components/chrome/palette.ts`: ARIA combobox and listbox in a `<dialog>`; Ctrl or Cmd+K, `/` outside text fields, or the landing prompt. Loaded by dynamic import on first open, with the index. Unknown slash text and no-match text end in a row that hands the text to the header search.
- `StatusLine.astro`: level, theme, modules done of 11, network; each item opens or focuses its control. `modulesDone` added to `src/lib/progress.ts`.
- Landing page is a prompt line and six starting points (Magnetic orderings listed as "coming", since no tool exists yet).
- Input Builder reads `?tag=NAME` and opens that tag card (the palette's tag commands use it).
