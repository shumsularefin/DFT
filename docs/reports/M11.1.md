## Offline & Worker Architecture
- Service worker (`scripts/build/sw.mjs` -> `dist/sw.js`) precaches core shell + `/offline/` fallback and runtime-caches visited pages, static `/_astro/**` immutable assets, and `/data/**`.
- Heavy computation (`moyo` symmetry, `rdkit` molecule sanitization, `kp1d`, orbital sampling) is offloaded to Web Workers so the main thread stays responsive.
- Note (corrected in M15.3, 2026-11-26): the earlier claim that the sandbox Chromium blocks `localhost` was wrong. Playwright runs against `localhost` with `PW_CHROMIUM_PATH=/opt/pw-browsers/chromium`, and Lighthouse CI runs locally with `CHROME_PATH=/opt/pw-browsers/chromium npx lhci autorun`. Local numbers on 2026-11-26 (one run per page, the 5 pages of `lighthouserc.json`, performance / accessibility / best practices / SEO): 404 100/100/100/66, landing 99/100/100/66, about 99/100/100/66, builder 100/100/100/66, changelog 100/100/100/66. SEO 66 is the site's noindex setting (draft PR #61 turns indexing on); `tests/e2e/offline.spec.ts` also runs locally.
