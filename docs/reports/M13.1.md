## What was built
- `src/lib/crystal/supercell.ts`: `buildSupercell` / `supercell(s, M)` for any integer 3x3 matrix with det > 0 (translations found exactly with the adjugate, coordinates wrapped with a 1e-10 snap, translation-major order, which equals the existing `supercell(s, na, nb, nc)` for diagonal M), `diagonalSupercell`, `hermiteNormalForms(n)`, `minimalCommensurateSupercell(s, k)` and `minimalCommonSupercell(s, ks)` (HNF by increasing determinant, cap 16, then Delaunay reduction from `reduction.ts`), `diagonalCommensurate`. Each built site keeps its parent index and lattice translation. M10.2 should reuse this file.
- `src/lib/magnetism/sublattice.ts`: `MagneticError` (typed codes), `selectMagneticSites` (default: d- and f-block sites), `magneticNeighbours` (periodic images, shells merged within 10 %), `pseudocubicGrid` (three B-B axis pairs, refuses with a reason when the sublattice is not pseudocubic or too distorted) and `fccGrid` (rock-salt cation sublattice).
- `src/lib/magnetism/orderings.ts`: `namedOrdering` (FM, A, C, G with a chosen or default axis, always reported with its reason; rock-salt type II), `orderingFromK` (s_j = cos(2 pi k . R_j), components other than 0 and 1/2 refused), `customOrdering`, `commonSupercell` (one cell, one atom order for all requested orderings), `fitCheck` (does-not-fit warning with the minimal cell), `netMoment`, `bondStatistics`, `isTrulyAntiferro`, `sitePermutations` and `enumerateCollinear` (2^N up to a global flip, classes under the moyo operations, N <= 12 by default), `configurationFromClass`.
- `src/lib/magnetism/magmom.ts`: `magmomFor` (POSCAR order from the M3.1 writer, compressed repeats, configurable non-magnetic value, optional split species `Mn1`/`Mn2` with the POTCAR consequence spelled out), `compressMagmom`, `formatMoment`, `validateMagmom` (V001 and V002 after an INCAR write and parse round trip), and `STARTING_MOMENT_GUIDANCE` (two sourced sentences, no per-element numbers).
- No UI (M13.2).

## Golden file (`gen_magnetic_reference.py`, new)
Independent path: pymatgen `make_supercell` and `get_neighbors`; minimal and common supercells by brute force over every integer matrix with entries in [-2, 2] (not an HNF search); signs from a Cartesian Q written from the definitions with each fixture's pseudocubic axes typed in (not detected); configuration classes by brute force over 2^N with spglib operations. Versions in `_meta`: pymatgen 2026.10.24, spglib 2.8.0, numpy 2.5.4.

| Fixture, ordering | k (parent cell) | minimal det | diagonal | nn parallel / antiparallel per site |
|---|---|---|---|---|
| cubic perovskite, FM | (0, 0, 0) | 1 | 1x1x1 | 6 / 0 |
| cubic perovskite, A (axis c) | (0, 0, 1/2) | 2 | 1x1x2 | 4 / 2 |
| cubic perovskite, C (axis c) | (1/2, 1/2, 0) | 2 | 2x2x1 | 2 / 4 |
| cubic perovskite, G | (1/2, 1/2, 1/2) | 2 | 2x2x2 | 0 / 6 |
| Pnma fixture, FM, A, C, G (axis b) | (0, 0, 0) | 1 | 1x1x1 | 6/0, 4/2, 2/4, 0/6 |
| rock salt, type II | (1/2, 1/2, 1/2) of the conventional cell | 2 | 2x2x2 | 6 / 6 |

Common supercell for FM, A, C, G: det 4 (cubic perovskite), det 1 (Pnma fixture). Symmetry-distinct collinear configurations: Pnma fixture 5 classes (4 Cu, 8 operations), rock salt conventional 3 (4 Na, 192), cubic 1x1x2 2 (2 Ti, 32), cubic 2x2x2 14 (8 Ti, 384). moyo returns the same operation counts as spglib for all four cells, including the pure translations of the 2x2x2 cell.
