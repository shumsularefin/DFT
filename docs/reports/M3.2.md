## The three rounding rules (Q-004 is OPEN)
With ratio = |b_i| / spacing (|b_i| includes 2 pi): `ceil` = ceil(ratio) (default, D-016); `round` = floor(ratio + 0.5); `plus0.999` = floor(ratio + 0.999). Each is clamped to at least 1. The function returns the rule it used.
**What the author must run (Q-004):** fcc Cu primitive, a = 3.61, KSPACING 0.3, 0.28 and 0.30145, then read the mesh VASP prints. Expected: ceil 11/11/11 for all three; round 10, 11, 10; plus0.999 11, 11, 10 (golden `kspacing_candidates`). Until then the default is only a safe guess, not VASP's rule.
