# M4.1 Output parsers and convergence analysis

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
All in `src/lib/vasp/`, pure, no DOM. 30 tests in `outputs.test.ts`.
- `oszicar.ts` `parseOszicar`: electronic steps (solver, N, E, dE, d eps, ncg, rms, optional rms(c)), ionic steps (F, E0, dE, optional mag, electronic steps per ionic step), `isMD` from `T=` lines, warnings.
- `outcar.ts` `parseOutcar`: version, NIONS, ENCUT, per-species ENMAX, NKPTS, NBANDS, every ionic step's TOTEN, energy without entropy and energy(sigma->0), external and Pulay pressure, last force block with maximum force and drift, E-fermi, reached required accuracy, elapsed time, magnetization, EDIFF reached per electronic loop. Each item carries its source line. Missing items give warnings, never exceptions.
- `csv.ts` `parseSeriesCsv`: header aliases, comma, tab, semicolon or space, decimal comma rejected with a message, line numbers on errors.
- `kseries.ts`: `encut_450` to 450, `kpt_0.04` to resolution 0.04, `k8x8x8` to 8; `orderByCost`.
- `convergence.ts` `analyzeSeries` (D-014 exactly), `energyPerAtom`, `pointFromOutcar` (default quantity energy(sigma->0), D-015). Pressure uses the same rule with an adjustable, heuristic 5 kB threshold.
- `num.ts`: Fortran number scanner shared by the parsers.
- Fixtures in `src/lib/vasp/__fixtures__/` with a README saying they are hand-written.
