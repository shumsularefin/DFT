# M5.4 Setyawan-Curtarolo k-paths (second convention)

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `src/lib/crystal/kpath/setyawan.ts`: `setyawanPath(symmetryResult)` returns the variant (23 pymatgen methods), special points in the reciprocal primitive basis, the path segments and pairs, and the conventional and primitive cells. Includes pymatgen's conventional-standard and primitive-standard transformations, an LLL reduction (triclinic) and `scLabelDisplay` (Γ, A₁).
- `src/lib/crystal/kpath/index.ts`: `kpathFor(api, structure, { convention })` switch between `HPKOT` (default) and `Setyawan-Curtarolo`, and `pointLabelDisplay`.
- Decision D-048, open items Q-038, THIRD_PARTY_NOTICES entry for pymatgen (MIT).

## Gates
- All 39 golden structures: spacegroup, variant, path segments, point-label set, every coordinate within 1e-6, primitive and reciprocal metric tensors within 1e-5. The golden set covers 20 of the 23 variants (asserted equal to the file's coverage list).
- Boundary tests: orcf3 (1/a^2 = 1/b^2 + 1/c^2) and mclc2 (reciprocal gamma = 90) built from synthetic cells check variant, path and key points against the pymatgen source.
- mclc4: a numerical scan shows no real cell reaches it (reciprocal gamma stays at or above 90 on the equality), so only an `it.todo` naming Q-038 exists.
- LLL: identity unchanged, a skewed cell reduced with unit volume. `npm run verify` passes.
