# M5.3 HPKOT k-paths (default convention)

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `src/lib/crystal/kpath/hpkot.ts`: `hpkotPath(symmetryResult, { withTimeReversal, threshold })` and the convenience `hpkotPathFor(api, structure, symprec)`. Returns the extended Bravais lattice (29 variants), special points in the basis of the reciprocal primitive lattice, the path segments, the conventional and primitive cells, P and invP, `warnings` for edge cases, and the augmented -k path when time reversal is off and the group has no inversion. `labelDisplay` maps `GAMMA` to Γ, `DELTA`/`LAMBDA`/`SIGMA` to Greek and `_n` to subscripts.
- `src/lib/crystal/kpath/expr.ts`: small safe parser for the table expressions (no `eval`).
- `src/lib/crystal/niggli.ts`: step-by-step port of spglib's Niggli reduction (needed by the triclinic branch).
- `src/data/kpath/hpkot/{variants,spacegroups}.json`, generated by `scripts/build/convert-hpkot-tables.mjs` from the seekpath 2.2.2 wheel (the script throws on any malformed line). Tested by `scripts/build/convert-hpkot-tables.test.ts`.
- Decision D-047: moyo `Spglib`-setting conventional cell plus SeeK-path's own transformations. Open items Q-037. New source S-055.

## seekpath files ported (MIT notice confirmed)
`seekpath/hpkot/__init__.py`, `spg_mapping.py`, `tools.py`, `spg_db.py` and `band_path_data/<variant>/*.txt` (seekpath 2.2.2). The full MIT text with the copyright line is in `THIRD_PARTY_NOTICES.md`, as is the BSD-3 text for spglib's `niggli.c`.

## Gates
- All 39 golden structures: spacegroup, `bravais_lattice_extended`, path segment list (in order), point-label set, every point coordinate within 1e-6, primitive metric tensor and reciprocal primitive metric tensor within 1e-5 (toBeCloseTo 5 digits). No test skipped.
- The 39 structures cover exactly the 29 variants of `_meta.coverage.hpkot_extended_bravais` (asserted).
- fcc Cu path is Γ-X, X-U, K-Γ, Γ-L, L-W, W-X (that is Γ-X-U | K-Γ-L-W-X).
- Augmented path: F23 (no inversion) gets primed points and doubled segments with `withTimeReversal: false`; a group with inversion does not.
- Edge case surfaced: a tetragonal I cell with c = a + 1e-8 reports "tI lattice, but a almost equal to c".
- Expression parser: every one of the table expressions parses and evaluates; Niggli: Niggli conditions, volume preserved, idempotent on the triclinic golden cells.
- `npm run verify` passes.
