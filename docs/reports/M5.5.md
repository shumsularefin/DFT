# M5.5 3D Brillouin zone and lattice viewer

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `src/lib/three/ViewScene.ts`: shared view behaviour (keyboard: arrows rotate, Shift for larger steps, + and - zoom, R resets; preset views; `data-camera` attribute for tests). Nothing animates by itself, so reduced motion needs no special case; damping is already off under reduced motion in `SceneController`.
- `BzScene.ts`: translucent zone faces with edges, Gamma at the origin, b1 to b3 as arrows with labels, special points as spheres with real HTML labels, the path as cylinders with cone direction ticks, optional k-mesh points, axes helper, views along b1, b2, b3 and the path start.
- `CellScene.ts`: cell outlines for every cell of the block, atoms as instanced spheres (one per element, plus an outline mesh), optional bonds, repeats 1 to 3 per axis, views along a, b, c.
- Pure helpers with tests: `labelPlacement.ts`, `solid.ts` (parallelepiped, orthographic projection with hidden edges), `palette.ts` (Okabe-Ito and contrast), `crystal/covalent.ts`, `crystal/cellAtoms.ts`. `SceneController` gained label removal and optional label decluttering.
- `BrillouinLab.tsx`, `UnitCellLab.tsx`, shared `SolidFallback.tsx` (flat view with azimuth and tilt sliders, hidden edges dashed). Registered in `Lab.astro` as `brillouin-zone` and `unit-cell`; demo pages `/design/brillouin-lab/` and `/design/unit-cell-lab/`.
- Decision D-049. Sources S-056 (WCAG 2.1) and S-057 (Okabe-Ito) added, both cited from memory.

## Gates
- Unit tests: label placement, SVG projection (cube 9 visible and 3 hidden edges at 30/20), palette contrast, covalent radii equal to the golden file, atom counts (conventional fcc 14 drawn from 4), scene keyboard and preset views, disposal.
- E2E (`tests/e2e/viewer-labs.spec.ts`, desktop and 360 px): 3D starts on request and closes, three is not in the initial JavaScript, keyboard control, fallback with WebGL disabled (dashed hidden edges, slider changes the drawing), axe clean in light and dark, no horizontal scroll at 360 px.
- Frame rate, measured with `scripts/perf/viewer-fps.mjs` (300 keyboard turns, two animation frames waited per turn, 1280x800, headless Chromium with SOFTWARE rendering): Brillouin zone median 16.7 ms per frame (p95 18.4), the 60 fps display limit; fcc Cu unit cell median 23.8 ms (p95 28.3), about 42 fps. This is not a laptop GPU measurement; with a real GPU both should be faster, but that was not measured. Scenes render on demand, so an idle view costs nothing.

## Not done / needs you
- Frame rate on a real mid-range laptop and on a phone is untested: please open both pages and report if either feels slow.
- Element colours are assigned by order, so the same element can get different colours in different structures (the legend names them). A fixed per-element scheme would need a cited source.
- Example structures in the cell viewer are drawing demos (Cu 3.61 and NaCl 5.64 Angstrom, values already used in the repo's fixtures); no claim is made about them.
