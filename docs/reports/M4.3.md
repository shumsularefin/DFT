# M4.3 Convergence plotter UI

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `/tools/convergence/` (`ConvergenceTool.tsx`, `ConvergencePlot.tsx`, `exportSvg.ts`, `convergence.css`).
  Inputs: multi-file drop (OSZICAR or OUTCAR, label from file or folder name), CSV paste (including `collect.sh` output), manual rows, sample data (visibly bannered as invented). Controls: series type, energy quantity (default energy(sigma->0)), atoms per cell, ENMAX, threshold slider 0.1 to 10 meV/atom (default 1), relative or absolute energy.
  Output: SVG plot with threshold band, converged marker and label, focusable points (arrow keys, Home, End), tooltip line, plain-language result at the current level, Pulay advice, pressure plot when every row has pressure (5 kB threshold labelled Heuristic), a results table as the text alternative, exports to SVG, PNG (2x) and CSV.
- Pure: `src/lib/vasp/convergenceView.ts` (ticks, formats, tooltip, explanation, CSV) and `seriesInput.ts` (files and CSV to rows to points); 25 MB file limit with a message.
- Library fixes: `parseSeriesLabel` searches folders and reads `kpt_NxNxN`; `parseSeriesCsv` takes x from a `label` column. This closes Q-032 item 4.
- Dependencies: `d3-scale` 4.0.2, `d3-shape` 3.2.0 (D-042). d3-axis and d3-selection were not added.

## Gates
- Unit: view-model ticks, meV formatting, tooltip text, explanation, CSV, label and file ingest, oversized files.
- E2E (both projects): three OSZICAR files give the marker at 450 eV (hand-worked series); a 6 meV threshold moves it to 400; ENMAX advice; pasted `collect.sh` output; SVG export parses and has 3 circles; PNG export is a 1280 px wide PNG; CSV export; keyboard traversal; axe in light and dark; 360 px without horizontal scroll.
- Size: `/tools/convergence/` initial JS 94.9 / 200 KB gzip, CSS 3.2 / 30 KB (d3-scale and d3-shape only, tree-shaken).
