# M4.2 Convergence series generator

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `src/lib/vasp/series.ts` (pure): `encutSeries`, `kmeshSeries`, `parseMesh`, `buildProject`, `estimateCost`, script templates (`runAllScript`, `collectScript`, `makePotcarScript`, `projectReadme`), `zipProject` (sync), `zipProjectAsync` (worker), `treeLines`, `MAX_RUNS = 40`.
- `src/components/tools/input-builder/SeriesPanel.tsx`: a "Convergence series" mode switch in the Input Builder. It reuses the structure step, the store's ENMAX, MAGMOM, job and rounding state, shows the folder tree, validates every generated INCAR with the M3.4 engine, blocks the download on errors, and downloads `convergence-series.zip`.
- `csv.ts`: two header aliases (`E_sigma0`, `pressure_kB`) so `collect.sh` output headers are recognised.
- Tests: `series.test.ts` (23) and `tests/e2e/convergence-series.spec.ts` (4 cases, run in both projects, the 360 px one in `mobile-360`).

## Layout of the zip
```
00_conv/encut_<E>/  POSCAR INCAR KPOINTS job.sh
00_conv/kpt_<res or NxNxN>/  POSCAR INCAR KPOINTS job.sh
run_all.sh  collect.sh  make_potcar.sh  README.txt
```
`collect.sh` uses the exact pipeline `grep "energy  without entropy" | tail -1 | awk '{print $NF}'` and `grep "external pressure"`.

## Gates
- Unit: ENCUT series (400 and 520), default resolutions to non-decreasing Cu meshes, exact KPOINTS text, every INCAR passes the validator, no POTCAR path, `bash -n` on all scripts, `collect.sh` run on fake OUTCAR files, zip round trip (sync and async), executable mode bits in the zip.
- E2E: 13 runs for ENMAX 400, zip contents, 40-run refusal, axe in light and dark, keyboard focus order, 360 px without horizontal scroll.
