## What was built
- `evaluateCompound` takes occupant lists for A, B, X and returns radii with their Shannon entries, t, mu, tau, charge-balance sum and checks, or `ok: false` with the reason and which site failed. It never returns a number when a radius is missing.
- tau is `ok: false` when rA = rB; rA < rB evaluates with `siteOrderWarning`.
- Checks all carry `heuristic: true` and a source ID where one applies.
- Oxidation data: 93 elements, 6 KB.
