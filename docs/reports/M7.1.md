# M7.1 Module 4: Hohenberg-Kohn, Kohn-Sham and the SCF loop (with SCF lab)

Status: done        Branch: claude/great-dijkstra-oj0kbx        PR: see docs/PROGRESS.md

## What was built
- `src/lib/physics/scf1d.ts`: port of `scripts/reference/gen_scf1d_reference.py` (same grid, operators, mixing, energy expression), reusing the M2.4 tridiagonal solver (`solveLowest` with c = 1/2). Returns every iteration (input and output density, potential, orbital and total energy, residual) and classifies the run as converged, oscillating (period-2 cycle detected from the densities), slow or diverging. The interaction matrix is cached per grid.
- Lab `scf-loop` (`src/components/labs/ScfLab.tsx`, badge Toy model): six-step cycle with the current check result, density, potential and log-residual plots, mixing slider 0.05 to 1.0, Z = 1 or 2, a repulsion switch, Previous/Play/Next/Last and an iteration slider (play is slower under reduced motion). States plainly that it is a 1D two-electron Hartree-Fock model, not Kohn-Sham DFT, and that VASP uses Pulay/Broyden mixing (AMIX, BMIX).
- Topics in `src/content/handbook/04-kohn-sham/`: `hohenberg-kohn-theorems`, `the-kohn-sham-idea`, `exchange-and-correlation`, `the-scf-loop` (lab), `when-scf-goes-wrong`.
- 35 questions in `module-04.json` (all 8 module 4 concepts published, at least 4 each); glossary: kohn-sham-orbital, effective-potential, hartree-potential, density-mixing, residual (Hohenberg-Kohn, exchange-correlation, functional, self-consistent-field already existed).
