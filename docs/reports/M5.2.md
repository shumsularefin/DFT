# M5.2 Brillouin zone geometry

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `src/lib/crystal/brillouin.ts`: `brillouinZone(reciprocalLattice)` returns `{ vertices, faces: { normal, planePoint, vertexIds }[], edges, volume }`. Method (D-046): box, then half-space clipping by the bisector plane of each candidate G (coefficients -2..2 of the Delaunay-reduced reciprocal basis, nearest first), vertices merged at 1e-9 relative, face vertices counter-clockwise seen from outside, edges from face loops, volume from tetrahedra to the origin. No Voronoi or hull code, so it is independent of the Qhull reference.
- `src/lib/crystal/reduction.ts`: `delaunayReduction` moved here from `pointgroup.ts` (re-exported there, no duplicate), plus `reduceBasis`. Tests in `reduction.test.ts`.

## Gates
- All 12 golden lattices: vertex, edge and face counts, volume (against both `bz_volume` and (2 pi)^3/V, within 1e-9 relative), the vertex set and the face plane points (G/2) within 1e-8 (compared as sets, one-to-one, because sorting floats with noise is not stable). Textbook counts sc 8/12/6, fcc 24/36/14, bcc 14/24/12, hexagonal 12/18/8; `fcc_skewed_basis` gives the same polyhedron as `fcc_primitive`.
- Structure: faces outward and counter-clockwise, vertices coplanar with their face, every edge shared by exactly two faces, every vertex inside all half-spaces, dependent vectors rejected.
- 300 seeded random cells (about 300 pass the filter): volume within 1e-9 of (2 pi)^3/V and Euler V - E + F = 2.
- Performance in Node, median of 20 runs per golden lattice: sc 0.32 ms, fcc 0.73, bcc 0.58, hex_ideal 0.46, hex_tall 0.44, tetragonal 0.35, bct 0.93, orthorhombic 0.30, rhombohedral 0.66, monoclinic 0.39, triclinic 0.71, fcc skewed 1.17 ms (limit 5 ms).
- `npm run verify` passes.
