# M7.3 report: Modules 6 and 7 (VASP files and running a calculation)

Status: done

## What was built

- `src/lib/vasp/outputReader.ts`: pure reader on top of the M4.1 parsers (`parseOszicar`, `parseOutcar`). Detects the file kind, writes one plain-language note per recognised line with a health mark (ok, warn, bad, info), and the summary checks: ionic steps, steps that hit NELM, total moment, last ionic energy change (OSZICAR); VASP version, ENCUT over largest ENMAX, electronic loops that missed EDIFF, entropy term T*S per atom, largest force against |EDIFFG|, magnetization, "reached required accuracy", "Elapsed time" (OUTCAR). Thresholds are VASP defaults (S-019) and the author's rules of thumb (S-041, S-042), marked Heuristic in the UI.
- Lab `output-reader` (`src/components/labs/OutputReader.tsx`, badge `computed`): local file input (read in the browser, never uploaded, 50 MB cap), paste box, two example buttons that load the hand-written parser fixtures with a visible "Synthetic example ... not the output of a real calculation" banner, EDIFFG and NELM inputs, checks list, electronic convergence plot (log |dE|), ionic-step table, line-by-line notes.
- Module 6 (`06-vasp-files/`): `poscar`, `kpoints`, `incar`, `potcar` (file `the-potcar-file.mdx`, because the POTCAR guard rejects any file name starting with POTCAR), `output-files`. POSCAR, KPOINTS and INCAR embed the clickable file explorer (M3.6) with the Field Handbook examples (Si diamond POSCAR, Gamma 8x8x8 KPOINTS) and the protocol relaxation INCAR. `output-files` has all 16 Field Handbook entries in one compact table. `potcar` shows only the build command and the four `grep` lines; no POTCAR content.
- Module 7 (`07-running/`): `the-workflow` (the five protocol steps quoted word for word, spelling included, inside a callout titled "The author's protocol", with the handbook's verified notes, the project folder layout and one INCAR per step), `job-scripts` (SLURM and PBS templates as produced by `jobScript`, NCORE and KPAR; covers concepts job-scripts and parallelization), `restarts-istart-icharg` (both tables and the rule), `reading-oszicar-and-outcar` (lab), `vaspkit-in-practice` (command map with the "menus change between releases" caveat, task codes, `~/.vaspkit` settings).
- 53 questions (`module-06.json` 23, `module-07.json` 30), at least 4 per concept; all 11 module 6 and 7 concepts published.
- Glossary: poscar, incar, potcar, oszicar, outcar, vaspkit, job-script.
- `topicPageClass` treats a page with `<VaspFileExplorer>` as an island page (it hydrates a React component).
- `FileExplorer`: the file figure is now keyboard focusable (`tabIndex=0`), fixing an axe `scrollable-region-focusable` violation that the long OSZICAR lines exposed.
