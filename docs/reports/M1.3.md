## What was built
- Chrome in `src/components/chrome/`, behaviour in `src/scripts/chrome.ts` (one module, no React). Without JavaScript the pages are complete; the level switch, theme toggle, progress, search and mark-complete controls are `.js-only`.
- Stores in `src/stores/` (level, theme, progress). A blocked or throwing localStorage leaves defaults and the controls keep working in memory (tested).
- `src/lib/progress.ts`: visit, complete, uncomplete, percent, per-module percent, union merge, defensive parse. `src/lib/topic.ts` gained `neighbors` and `levelNotes`.
- `HandbookLayout.astro` (sidebar with module percent and ticks, breadcrumbs, mark complete, previous and next); the topic route now uses it and carries `data-pagefind-body` plus module and level-notes metadata.
- Header navigation lists Handbook, Tools, Studio, Builder, Practice. The last three point at their "Coming soon" card on `/tools/` so no link is dead.
- `INDEXING_ENABLED = false` in `src/lib/site.ts` drives the robots meta tag and a generated `robots.txt` (replaces `public/robots.txt`); sitemap excludes `/design/` and `/offline/`.
- `scripts/build/check-links.mjs` (with test, in `verify` as `npm run links`) checks every internal link and fragment in `dist/`.
- Landing, About, Privacy copy says plainly that the site is under construction and that sync does not exist yet.
