# M3.3 INCAR data model, presets and handbook extraction

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `scripts/build/extract-handbooks.mjs`: reads both handbooks with Playwright, asserts counts (Field: OUT 16, INP 4, TAGS 24, TROUBLE 22, RECIPES 7; Workflow: 53 dictionary rows, 20 error rows, 15 INCAR blocks = 11 INCAR + 2 phonopy configs + 2 fragments). Output in `scripts/__generated__/` is deterministic (re-run gives identical files).
- `scripts/build/build-vasp-data.mjs`: generates `src/data/vasp-tags.json` (71 tags) and `src/data/incar-presets.json` (16 presets).
- `src/lib/vasp/incar.ts`: `parseIncar`, `writeIncar`, `parseLogical`, `expandRepeats`, `magmomCount`.
- Tests: `incar.test.ts` (27) and `incar-data.test.ts` (Zod schema, known tags, sources in the register, related tags, correction records, extraction counts).

## Honesty notes
- Defaults, typical values and intermediate/pro text come from the handbooks. Where they state no default, the field says so (Q-028). Minimum VASP versions were not checked.
- Beginner and "what breaks" text is new wording; it needs author review.
- Corrections (`fixed` records) are carried into `corrections`; originals are not shown as current (D-018).

## Left out on purpose
Phonopy `band.conf` / `mesh.conf` (not INCAR), Field Handbook OUT/INP/TROUBLE/RECIPES records (later stages), the 20 error rows (M3.4).
