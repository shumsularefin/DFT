# M3.6 Clickable file explorer

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- `src/lib/vasp/annotate.ts`: `annotate(kind, text)`, `mergeAnnotations`, `POTCAR_FIELDS`. POSCAR (comment, scale, lattice vectors, species, counts, selective dynamics, Direct or Cartesian, one line per atom, labelled by species), KPOINTS (Gamma, Monkhorst-Pack, Auto, explicit list, line mode), INCAR (every tag from the database; unknown tags flagged "not in the database"; unreadable lines reported, not thrown).
- `src/components/labs/FileExplorer.tsx` (+ CSS): annotated lines are buttons; side panel shows the text at the reader's level, "why this value", "what if it were different" and a collapsible full tag card for INCAR tags. Keys: arrows, Home, End, Enter, Escape. Touch targets 44 px.
- `src/components/labs/PseudopotentialHeader.tsx`: header field meanings only (TITEL, POMASS, ZVAL, RWIGS, ENMAX, ENMIN, LEXCH). No values, no dataset text.
- MDX: `<VaspFileExplorer kind code />` and `<PseudopotentialHeader />`, registered in the topic page. Verified by a temporary use in a topic (build passed, reverted).
- Demo page `/design/explorer-demo/` (not indexed) used by the e2e tests.
- Small CSS for the existing tag card classes (`ib-card`, `ib-chip`).
