### M14.3 (planar averages)
- Finding: no pymatgen golden file. The planar average was checked only by a hand-computed test.
  **Fixed:** `scripts/reference/gen_volumetric_reference.py` writes a synthetic LOCPOT (6x5x16, slab-like profile plus seeded noise) and a spin CHGCAR with pymatgen. The hand-computed test stays.

### M9.3 (feasibility runtime model)
- Finding: `0.02 * nsites^2.5 * spin 2 * metal 1.5 * 5 steps` core-hours had no source, and the exponent disagreed with the "O(N^3)" text of the size rule.
  **Fixed (D-091):** the estimate is now relative: (nsites / 4)^3, times 2 for spin (S-010, S-019), and the text reads "about N times the cost of a 4-atom non-magnetic cell". The metal factor, step count, cores input and time buckets are gone. The UI line on the project card changed to match (minimal change), and a unit test was added.
