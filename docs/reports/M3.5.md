# M3.5 Input Builder UI

Status: done        Branch: claude/vigilant-newton-ws593b        PR: see docs/PROGRESS.md

## What was built
- Page `/tools/input-builder/` (`pageClass="tool"`, one React island). Linked from `/tools/`; the Tools page "Coming soon" count went from 7 to 6.
- Six steps in `src/components/tools/input-builder/`: Structure (paste or file, 25 MB cap, hand-off from other tools), Task (preset, variant, system type, ENMAX, ENCUT suggestion, optional ZVAL), Settings (tag table, search and group filter, Explain card at the reader's level, add tag with placeholder, reset to preset, per-species MAGMOM and DFT+U helpers), Check (VASP 5.4/6.3/6.4, all M3.4 issues with title, why, detail, source links, fix button; live region with counts; acknowledgement gate), K-points (Gamma, Monkhorst-Pack, KSPACING in INCAR, line-mode placeholder; mesh readout; centring advice; Q-004 rule warning), Job script and download (SLURM or PBS, Heuristic NCORE and KPAR hints, POTCAR cat command and licence note, individual files, zip, share link).
- Pure libraries with tests: `src/lib/vasp/jobscript.ts` (8 tests), `src/lib/vasp/builder.ts` (18 tests).
- Dependency: `fflate@0.8.3` (listed in `docs/verified-stack/package.json.reference`).
- A banner states the VASP 5.4 to 6.4 target and that the tool generates inputs, not guarantees.
