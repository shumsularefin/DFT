# M12.4 Guided path: learn DFT step by step in 3D

Status: done        Branch: claude/m12-4-guided-path        PR: see docs/PROGRESS.md (stacked on M6.5, PR #41)

Tier B (fast model), as the work order says. Dependencies M12.2, M7.2 and M13.2 are done.

## What was built
- **`src/content/learn/stations.json`**: the fourteen stations of the work order, in order. Each has a title, a badge, a text alternative, exactly three plain sentences, one picture (a scene preset or a plot that already exists), one "try this" (a slider or a choice), a link to the full handbook topic, and source ids (those of the linked topics).
- **`src/lib/learn/stations.ts`** (pure): the station format, `validateStations` (the linter), `resolveStation` (the picture for a slider value or chosen option) and `allStates`. **`stations.test.ts`** (8 tests): the file passes the linter, order, every reachable state of every station draws, every linked topic and source exists, the badge equals the badge of the plot or scene shown, scene choices keep the badge, bad values fall back to the start, no em dash, the linter catches a broken station.
- **`src/components/learn/GuidedPath.tsx`, `learn.css`, `src/pages/learn.astro`**: one station at a time; buttons, Left and Right arrows, Page Up and Down, Home and End, and a numbered jump list; focus moves to the station title; the current station is kept in the URL hash. Plot stations draw flat SVG (the renderer loads as its own chunk after the page opens). Scene stations reuse one `Scene` island, which gained `initialLive` and `onLiveChange` so a reader who opened 3D keeps it from one scene station to the next, and now resets step and camera when the preset changes. Only one canvas exists at any time (D-058).
- **Progress**: each station opened is marked visited (`learn/<id>`); reaching the last marks `learn/path` complete. Handbook topic percentages are unchanged.
- **Header**: a "Learn" link. The shell e2e that expects the first nav link to be Handbook was updated for the new first link (a nav change, not a weakened check).
- D-084 in `docs/DECISIONS.md`; `CHANGELOG.md` entry.
