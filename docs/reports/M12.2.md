## What was built
- `src/lib/scene/spec.ts`: `SceneSpec` type and `validateSpec`/`assertSpec` (missing `alt`, spin count not equal to site count, bad badge, repeat, plane, camera and step fields are errors).
- `src/lib/scene/resolve.ts`: spec plus step to geometry (atoms with boundary images, cell edges, bonds, polyhedra, spin arrows, Miller planes, real and reciprocal vectors, labels). `project.ts`: orthographic projection with painter's order and `rotateCamera`. `svg.ts`: one SVG string used at build time and in the browser. `polyhedra.ts`: neighbours with periodic images and a convex hull that merges coplanar points. `canvasSlot.ts`: the D-058 one-live-canvas rule.
- `src/lib/three/SpecScene.ts` (built on `ViewScene`): instanced atoms with outlines, translucent polyhedra and planes, solid or open-headed arrows with HTML `+`/`-` labels. Loaded only by dynamic import.
- `src/components/scene/Scene.tsx` (island: flat SVG first, "View in 3D", Along a/b/c and Isometric, Reset view, arrow keys in both modes, Previous/Next step with a live region), `SceneSvg.astro` (no JavaScript), `Scene.astro` (MDX `<Scene id="..." />`, registered in the topic page; a topic that uses it gets page class `island`).
- 14 presets in `src/data/scenes/` and 10 named structures in `src/data/scene-structures.json`, written by `scripts/data/build_scenes.py`. `perovskite-octahedra` has a 3-step story. Demo page `/design/scenes/` (not indexed).

## Test changes (stated openly)
None weakened. `topic.test.ts` gained a case. The first e2e draft waited for every island to hydrate; islands are `client:visible`, so the spec now scrolls each scene into view first.
