## What was built
- `dist/sw.js`: precache `/`, `/offline/`, `/404.html` plus any `/_astro` CSS/JS those pages reference (none yet: CSS is inlined and the registration script is inline). Runtime: `/_astro/**` CacheFirst (1 year, 200 entries), `/data/**` and `/pagefind/**` StaleWhileRevalidate, navigations NetworkFirst (3 s) with `precacheFallback` to `/offline/`. `skipWaiting` and `clientsClaim`. No `.wasm` or datasets are precached. Registered in production only, after `load`, only if `navigator.serviceWorker` exists.
- `BaseLayout` gets a `pageClass` prop (default `content`) written to `data-page-class` on `<html>`, plus manifest, SVG favicon and theme-color links.
- Icons (192, 512, maskable 512) are rendered from inline SVG by Playwright's Chromium (no new dependency) and committed.
- `check-size.mjs`: per page it gzips initial JS (script tags, modulepreload, static imports, inline scripts) and CSS (links and inline styles) and compares with `budgets.json`; a page without `data-page-class` fails.
