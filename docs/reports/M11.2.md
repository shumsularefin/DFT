# M11.2 Report: Accessibility and security audit

## Summary
Audited WCAG 2.2 AA contrast, keyboard navigation paths, Content Security Policy headers in `firebase.json`, and switched Lighthouse CI assertions to `error` (keeping `categories:seo` and `is-crawlable` off until indexing is enabled).

## Accessibility Findings & Verification
- **Color contrast (`npm run contrast`)**: All 46 light-theme and dark-theme foreground/background pairs pass WCAG 2.2 AA (`>= 4.5:1` for text, `>= 3:1` for UI controls/focus rings). Minimum text contrast is `5.49:1` (light accent on surface) and `6.00:1` (dark accent on surface).
- **Keyboard walkthroughs**:
  - Input Builder, k-path tool, Tolerance Factor Explorer (including shared `PeriodicTable`), Screening Studio, Material Builder (Crystal mode + Molecule mode keyboard "Add atom" fallback), Research Planner, Calculation Review, and Practice all expose native buttons, labels, `role="toolbar"`, `aria-pressed`, and `aria-label` landmarks.
  - Screen-reader pass (NVDA / VoiceOver): flagged as pending for the author in a desktop OS environment.
- **Responsive & CSP e2e**: Added `tests/e2e/a11y-csp.spec.ts` verifying zero horizontal scroll at 360 px width and zero `securitypolicyviolation` events across core routes in GitHub Actions CI.

## Security & Content Security Policy (`firebase.json`)
Added a strict `Content-Security-Policy` header alongside `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`, and `X-Frame-Options: DENY`:
- `default-src 'self'`
- `script-src 'self' 'unsafe-inline' 'wasm-unsafe-eval'` (`'wasm-unsafe-eval'` required for `moyo` and `RDKit` WebAssembly; `'unsafe-inline'` retained for Astro inline theme/level initialization and hydrated island bootstrap scripts)
- `worker-src 'self' blob:` (required for Vite module Web Workers)
- `connect-src 'self' https://*.googleapis.com https://*.firebaseio.com https://identitytoolkit.googleapis.com https://securetoken.googleapis.com` (for optional user-initiated Firebase sync)
- `img-src 'self' data: blob:; style-src 'self' 'unsafe-inline'; font-src 'self' data:; object-src 'none'; frame-ancestors 'none'; base-uri 'self'`

## Lighthouse CI (`lighthouserc.json`)
- Promoted `categories:performance`, `categories:accessibility`, `categories:best-practices`, and individual SEO audits (`document-title`, `meta-description`, `http-status-code`, `link-text`, `crawlable-anchors`, `canonical`, `robots-txt`, `image-alt`) from `warn` to `error`.
- Left `categories:seo` and `is-crawlable` as `off` until the author merges the M11.3 indexing branch.
