# M12.3 Every question gets a visual

Status: done        Branch: claude/m12-3-question-visuals        PR: see docs/PROGRESS.md (stacked on M6.4, PR #35)

Tier B (fast model), as the work order says.

## What was built
- `src/lib/visual/plots.ts`: 18 pure SVG plot generators (`box-levels`, `box-wave`, `box-mix`, `hydrogen-radial`, `hydrogen-levels`, `orbital-slice`, `occupation`, `spin-ladders`, `de-broglie`, `band-chain`, `band-gap`, `exp-wall`, `grid-wall`, `cost-scaling`, `scf-trace`, `scf-density`, `density-box`, `steps`). They reuse the tested physics modules (box, hydrogen, real spherical harmonics, determinant counting, cost model, SCF toy lab, tight-binding chain). No new constant or formula. Badges: computed, toy-model or illustrative. Negative orbital lobes are hatched, series differ by dash pattern, so nothing depends on colour alone.
- `src/lib/visual/resolve.ts`, `figures.ts`: turn a question's `visual` into a figure (flat SVG, badge, caption, alt, scene spec). A bad scene or plot id fails the build.
- `visual` is a validated union on every question (`scene`, `plot` or `none` with a reason). `scripts/lint-questions.mjs` requires it on every question, lists the exemptions and prints "visual exemptions: 7 of 128".
- All 128 questions in modules 1 to 4 have a visual.
- `QuestionFigure`: build-time SVG, badge, caption, "Text description", and for crystals a "View in 3D" button that lazy-loads the Scene island. Topic pages pass figures to the Check island and the noscript list (the picture stays with JavaScript off). `/practice/` fetches `/data/figures.v1.json` once after load instead of inlining all figures.
- `docs/CONTENT_GUIDE.md` section on visuals, D-065, CHANGELOG line.

## Exemptions (7 of 128, under the 6 percent cap)
q-how-to-use-1 to 4, q-roadmap-1, q-roadmap-4, q-roadmap-8. Reason on each: a picture would only restate the answer, because the question is about using the site.

## Answer-leak review
I looked at every figure in a contact sheet. Three gave away their answer and were changed: q-box-3 (nodes no longer marked), q-orb-2 (one p orbital, not all three), q-box-2 (one box, not two). Captions are neutral. A test asserts no numeric answer is printed as text. This is a manual check; new questions need the same care (CONTENT_GUIDE).

## Science traceability
No new constants, formulas or data tables. Plots call the existing tested modules (sources S-047, S-048, S-049 and the ones those modules cite). Toy-model and illustrative badges are shown on the figures.
