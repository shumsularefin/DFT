# M12.5 See what a tag does

Status: done        Branch: claude/m12-5-tag-visuals        PR: see docs/PROGRESS.md (stacked on M7.2, PR #37)

Tier B (fast model), as the work order says.

## What was built
- `src/data/tag-visuals.json`: one entry per covered tag (plot or scene id, badge, source ids, captions at three levels, alt text, example value, value cases).
- `src/lib/vasp/tagVisual.ts`: `visualFor(tag, value, {structure, incar})`, pure. An unknown tag or a value the tag data does not document gives `null`, never a wrong picture. `tagVisualTags.ts` is the tiny tag list the card reads without loading the mappings.
- Six new plots in `plots.ts`: `ispin-ladders`, `dof-cell`, `ionic-steps`, `ediff-trace`, `force-band`, `sigma-width`; `pw-parabola` takes `kmax`, `kmesh-grid` takes `m`.
- `TagVisual` (React) behind a "Show me" disclosure in `TagCard` (Input Builder and file explorer, where it follows the value in the file); `<TagVisual tag="..." />` for MDX, used in four module 5 topics. Nothing loads until the disclosure is opened; three.js loads only on "View in 3D".
- Tests: 30 in `tagVisual.test.ts` (schema: every tag, plot, scene and source id exists, badge equals the generator, no em dash, documented values give documented figures, unknown values give none); e2e `tag-visual.spec.ts` (6 tests, desktop and 360 px: no request for three before or after Show me, ISPIN switch changes the figure and text, undocumented value gives a message, keyboard open, axe, no overflow).

## Science traceability
Sources S-011, S-014, S-016, S-019, S-031, S-041, S-042, S-049. No new constant. Captions repeat only what `vasp-tags.json` says.
