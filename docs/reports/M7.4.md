## What was built
- **Module 8** (`src/content/handbook/08-convergence-and-errors/`): `why-converge`, `encut-convergence`, `kpoint-convergence`, `scf-trouble`, `relaxation-trouble`, `common-errors`. All use `noLab: true`; `common-errors` embeds the finder with the `<ErrorFinder />` component. The ENCUT topic walks through the existing input-builder series panel and convergence plotter instead of adding a new tool.
- **`src/data/errors.json`**: 33 unique entries merged from the Field Handbook's 22 troubleshooting entries (S-041) and the Workflow Handbook's 20 error rows (S-042); built by `scripts/build/build-errors.mjs` from `scripts/__generated__/*.json`. Fields: `id`, `title`, `category`, `messages`, `keywords`, `symptoms`, `plain`, `causes`, `fixes` (each with an optional `incar` change), `related`, `sources` (handbook entry ids: `t-...` for the Field Handbook, `w-NN` for Workflow Handbook row NN).
- **Matching engine** `src/lib/errors/match.ts`: exact stage (a printed message found in the pasted text, ranked by matched length, all hits returned so a log with two errors gives both) then a fuzzy keyword stage (stemmed tokens, inverse document frequency, one-letter typo tolerance, phrase bonus) used only when nothing matched exactly. Pure functions; nothing leaves the page.
- **`/errors/` page** and `ErrorFinder.tsx`: paste or type, example chips, results with the plain sentence at every level, causes and the INCAR change at Intermediate, and source ids at Pro; "nothing matched" opens a browse-by-category list. Added to `/tools/` and the axe page list.
- **Questions**: `module-08.json`, 24 questions (4 for each of 6 concepts), 2 with a reasoned "no picture" exemption. One new plot, `conv-series` (illustrative; prints no numbers so a question can ask for the value).
- Concepts: 4 published, 2 added (`scf-troubleshooting`, `relaxation-troubleshooting`); 4 glossary terms (`convergence`, `pulay-stress`, `smearing`, `nbands`).
