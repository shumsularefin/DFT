Status: done        Branch: claude/zen-bardeen-qzm2f2        PR: see docs/PROGRESS.md

## What was built
- Six topics in `src/content/handbook/08-convergence-and-errors/`: `why-converge`, `encut-convergence` (ENCUT lab), `kpoint-convergence` (k-mesh lab), `scf-trouble` (output reader), `relaxation-trouble`, `common-errors` (embeds the finder). All fixes and numbers come from the two handbooks (S-041, S-042); nothing was added from outside them except wording.
- `src/data/errors.json`: 32 merged entries (id, title, category, exact messages, keywords, symptoms, plain sentence, ordered causes, ordered fixes with INCAR changes, related tags, handbook source ids).
- `src/lib/vasp/errorFinder.ts`: local matcher. Tiers: exact message (case and spacing ignored, `re:` regexes supported), distinctive routine name (ZBRENT, BRMIX ...), keyword overlap per line (idf weighted, one typo tolerated). Level view: Beginner gets the plain sentence, first cause, first two fixes; Intermediate all of them plus the covered messages; Pro adds handbook ids.
- `ErrorFinder` lab (id `error-finder`), page `/errors/`, a card on `/tools/`. Paste, file input (5 MB, read locally), example button, ranked results, "nothing matched" with browse by category.
- 30 questions (`module-08.json`, 5 per concept, 6 concepts published), glossary: convergence-test, charge-sloshing.
