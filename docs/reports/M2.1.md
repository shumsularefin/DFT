## What was built
- `src/lib/three/capabilities.ts`: `hasWebGL(doc)` tries webgl2 then webgl and never throws; `shouldStart3D` (a click always starts if WebGL exists; auto start needs the view on screen and motion allowed).
- `src/lib/three/SceneController.ts`: the one base class (D-007). Render on demand (a frame only when something changed, one frame per burst of requests), a loop only while animating or while OrbitControls damping settles, pause when the page is hidden or the view is off screen, `setDprCap` (default 2), reduced motion (no loop, damping off, `step()`), HTML label overlay placed by projection, instanced spheres, line segments, polylines, lights, and `dispose()` that removes every listener and observer and disposes geometries, materials, textures, controls and the renderer. Injectable environment and factories (D-030).
- `src/components/labs/`: `LabShell` (title, goal, badge `illustrative | toy-model | computed`, controls, view with `aria-describedby`, readouts, visible text description, "What to notice", reset, loading and error states), `Lazy3D` (poster, dynamic import, flat fallback on no WebGL or failed import or failed start, optional auto start), `Fallback2D` (SVG with azimuth and elevation sliders; `project.ts` holds the pure projection).
- Demo `/design/lab-demo/` (noindex, `pageClass="island"`): a 3 by 3 by 3 grid of spheres in a cube. No science.
- `Badge` now has a `computed` variant and a React twin (`Badge.tsx`); labels and shapes moved to `src/lib/badges.ts`, CSS to `Badge.css`.
- `check-size.mjs` gained `checkLazyChunks`; `budgets.json` has `lazyChunks.three`.
