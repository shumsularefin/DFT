# M12.6 A structure view wherever a POSCAR appears

Status: done        Branch: claude/m12-6-structure-view        PR: see docs/PROGRESS.md (stacked on M13.2, PR #33)

Tier B (fast model), as the work order says.

## What was built
- `src/lib/crystal/measure.ts`: minimum-image vector, distance, angle, dihedral (atan2 form, IUPAC sign) and coordination (covalent-radius rule, tolerance 1.15, all periodic images). `@source S-021`. Tested on the golden rock-salt NaCl from `tests/reference/kpaths.json`: nearest Na-Cl distance is a/2, Cl-Na-Cl angles are 90 and 180 degrees (2x2x2 supercell), coordination 6, minimum image across the cell boundary, dihedral sign and planar cases.
- `src/lib/vasp/poscarLines.ts`: file line numbers of the atom coordinate lines (with and without a species line, Selective dynamics, non-POSCAR text gives none).
- `src/components/structure/StructureView.tsx`: summary sentence, `Scene` (badge `computed`, bonds, cell, spin arrows when a MAGMOM matches the atom count), Measure mode, a keyboard-operable site table (first 400 rows), readout for 2, 3 or 4 picks, coordination for one selected site.
- Embedded in: the file explorer (`view` prop, linked both ways with the coordinate lines; `VaspFileExplorer.astro` passes it through), the Input Builder structure step (shows MAGMOM arrows), and the k-path tool ("Your cell in real space", on the standardized primitive cell).
- Demo pages: `/design/explorer-demo/` (one view) and `/design/structure-demo/` (two views, used to test one live canvas).
- D-075, CHANGELOG line.
