## What was built
- `src/styles/{fonts,tokens,base}.css`. Accent is a restrained blue on a cool neutral scale. Motion durations are 0 unless `prefers-reduced-motion: no-preference` (so every transition honours reduced motion).
- Inline theme script in `<head>` reads `dft:theme` using the same `{ v, data }` envelope as `src/lib/storage.ts`, so M1.3's toggle can use `setJSON('theme', ...)`. No stored choice: `prefers-color-scheme` decides.
- Components in `src/components/ui/`. Astro components with global scoped-by-class styles; Slider and Toggle are React (hydrated `client:load` on the gallery). Tabs and the CodeBlock copy button are small vanilla scripts (progressive enhancement: without JS all tab panels show stacked and no copy button appears), so content pages do not pay for React.
- Fonts: 400 and 600 are used; 500 is declared but unused, so it is not downloaded. Only latin files are referenced.
- Fallback metrics were measured with fontTools from the real font files (letter-frequency weighted average advance for `size-adjust`; hhea ascent/descent divided by `size-adjust` for the overrides), against Liberation Sans/Mono. Method is in the comment at the top of `fonts.css`.
- `contrast.mjs` also checks that the `prefers-color-scheme` block equals the `data-theme="dark"` block.
- `check-size.mjs` now also counts Astro island component and renderer chunks (they were invisible to the check as dynamic imports); unit-tested.

Keyboard-only walkthrough (automated in `tests/e2e/design.spec.ts`, and the intended manual path):
- **Tabs**: Tab focuses the selected tab only (others have `tabindex=-1`); Right/Left move and wrap, Home/End jump; selection follows focus and the panel changes; Tab then moves into the panel.
- **Disclosure**: Tab to the summary, Enter or Space opens and closes it (native `<details>`).
- **Slider**: Tab focuses the range; Left/Right change by one step (520 to 540 eV), Home and End go to 200 and 800; the readout updates.
- **Button / Toggle**: Tab reaches each, Space or Enter activates; focus ring is a 3 px outline in the `--focus` token (contrast above).

## Decisions made and open questions raised
None new. Choices inside the work order: Tabs uses vanilla JS rather than React; `--border-strong` is a separate token for control borders (3:1) while `--border` is decorative; Plex 500 is declared but unused to keep first-view fonts under 100 KB.
