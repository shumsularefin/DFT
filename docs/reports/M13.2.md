## What was built
- `src/lib/magnetism/export.ts`: per-configuration POSCAR and INCAR (`ISPIN`, `MAGMOM`, `LORBIT = 11`, optional LDAU block from user-typed values), the V001/V002 validator run on every output, README (cell policy, caveats, what is missing), zip layout (`FM/`, `A/`, `C/`, `G/` or `config-NN/`, `README.md`, `make_potcar.sh`), and the "why this cell" sentence.
- `src/components/tools/magnetic/`: `MagneticTool.tsx` (left: cell, magnetic elements, starting moments, cell policy, DFT+U; centre: tabs and the `Scene` island with spin arrows, polyhedra toggle, 2x2x2 neighbour cells, axis choice for A and C drawn as a vector; right: transcript, MAGMOM, INCAR, downloads), `magneticModel.ts` (pure), `magnetic.css`. Page `src/pages/tools/magnetic.astro`; card on `/tools/`; search entry.
- Custom mode: site buttons selectable by click or keyboard (`U`, `D`, `0`, arrow keys), plus a table with a spin select and a moment field per site.
- Enumerate: optional diagonal repeat, symmetry from the moyo worker, `enumerateCollinear`, a checkbox per class, export of the checked ones.
- Hand-offs: `ToolId` gained `magnetic`; the structure hand-off carries an optional `magmom`; the Input Builder sets `ISPIN` and `MAGMOM` from it; "Open in the k-path tool" sends the structure. Hand-off in from the Material Builder works through the existing structure hand-off.
- D-062 in `docs/DECISIONS.md`.

## Science traceability
No new constants or formulas. Geometry, signs and counts come from the M13.1 library (S-058, S-059); the MAGMOM and ISPIN rules from S-041; LDAUTYPE = 2 from S-014. Starting moments and U, J are typed by the user; no default is shown (S-042, S-065 guidance text only).
