Your protocol (fixed)

These five steps are the working protocol for this handbook and are reproduced exactly as written. Every INCAR and command in the core sections follows them. The notes under each step say what the VASP wiki (vasp.at/wiki), the VASPKIT 1.5 tutorials and the standard literature say about it.

1

Relaxation

“Prepare four INPUT files and changes it as it requires. Run relaxation with encut of 1.3 of Enmax. Ediff, ISPIN, Magmom. INCAR can be prepared from VASPKIT.”
  • verifiedENCUT = 1.3 × ENMAX: the VASP wiki notes the default cutoff often has to be raised by about 30% to converge the stress tensor (Pulay stress). Use the largest ENMAX among your species: grep ENMAX POTCAR.
  • verifiedForce criterion EDIFFG = -0.005 or -0.001 eV/Å. A negative EDIFFG stops when every force is below |EDIFFG| (VASP wiki).
  • noteISPIN = 2 with one MAGMOM value per atom, in POSCAR order. VASPkit: 101 → SR (add MG for spin: SRMG).
2

SCF in the same folder

“Same folder RUN SCF calculation. ISTART should be 1, INCAR will be generated from VASPkit. Try Converge repeatedly. For DOS, LORBIT = 11.”
  • verifiedISTART = 1 reads the WAVECAR left by the relaxation (VASP wiki: ISTART).
  • verifiedIBRION is not written. With NSW = 0 VASP’s default is already IBRION = −1 (VASP wiki: IBRION).
  • verifiedISMEAR = 0, SIGMA = 0.05 as in the VASPkit template. The wiki recommends Gaussian smearing with a small SIGMA for semiconductors and insulators, and warns against the default ISMEAR = 1 for them.
  • verifiedLORBIT = 11 writes the projected DOS and PROCAR. The DOS is read from this SCF run with VASPkit 111 / 113.
3

Band structure

“For BAND, Run SCF again without ICHARG=11 in INCAR, then generate KPATH.in which will be KPOINTS vaspkit 3 - 303. For data analyasis, vaspkit 21 211.”
  • verifiedThe SCF without ICHARG = 11 on a uniform k-mesh writes the converged CHGCAR. 303 writes KPATH.in, which becomes the k-path for the bands, and 211 reads the result.
  • wiki ruleThe VASP wiki says a line-mode k-path “is not suitable for self-consistent calculations”. So the KPATH.in eigenvalues must come from one of two validated routes (details in Band structure):
    (A) VASP ≥ 6.3: one SCF without ICHARG = 11, with the uniform mesh in KPOINTS and KPATH.in copied to KPOINTS_OPT;
    (B) a run with KPOINTS = KPATH.in that reads the SCF CHGCAR (ICHARG = 11). This is the INCAR in the VASPKIT band tutorial.
4

Elastic properties

“For elastic Properites, Prepare INCAR similar to Relaxation, but IBRION will be 6-8 and ENCUT=620. Comment out NCORE. vaspkit 2 - 203.”
  • verifiedThe VASP wiki states that IBRION = 6 with ISIF ≥ 3 calculates the elastic constants (six finite lattice distortions, clamped and relaxed ions). Use IBRION = 6, ISIF = 3.
  • verifiedENCUT = 620: stress needs the higher cutoff, as in step 1.
  • verifiedComment out NCORE. VASP runs IBRION = 6 without band parallelization (NPAR = number of ranks); NCORE in the INCAR can stop the run.
  • verified203 reads TOTAL ELASTIC MODULI from OUTCAR (VASPKIT tutorial).
5

Optical properties

“For Optical Properites, run SCF again up to -06 to -08 and then generate INCAR from vaspkit. After SCF calculate get the grep NBANDS OUTCAR. Then take NBANDS 3 times of it with closest ceiling numbers. Add ISPIN and magmom if requires. For data analysis, vaspkit 71 - 711.”
  • verifiedVASP wiki (LOPTICS): reasonable results “are usually only obtained if NBANDS is roughly doubled or tripled” with respect to the default. The wiki examples use EDIFF = 1E-8.
  • verified“Closest ceiling”: VASP itself increases NBANDS until it is divisible by the number of cores (or by NCORE) (VASP wiki: NBANDS). Round 3 × NBANDS up to that number.
  • verifiedVASPkit: 101 → OP, then 711. Wiki values: CSHIFT = 0.1, NEDOS ≈ 2000.

ISTART and ICHARG: what is read, what is kept

These two tags decide whether a run starts from scratch or continues from files in the folder. Most “why does my band structure look wrong” problems trace back to them.

ISTARTMeaning
0Fresh start, random wavefunctions. Default when no WAVECAR exists.
1Read WAVECAR; keep ENCUT constant (basis rebuilt for the new cell). Default when WAVECAR exists. Your SCF-after-relax setting.
2Read WAVECAR; keep the basis set constant. Used rarely, e.g. for consistent energies along a strained series.
ICHARGMeaning
0Density built from the initial wavefunctions. Default when ISTART > 0.
1Read CHGCAR and continue self-consistently. Use to restart a stalled SCF.
2Superposition of atomic densities. Default for a fresh start.
11Read CHGCAR and keep it fixed (non-self-consistent). Band structures and dense-mesh DOS.
Rule

An ICHARG=11 run inherits its physics from the CHGCAR. Keep ENCUT, ISPIN, MAGMOM, LMAXMIX, the functional and any LDAU tags identical to the SCF that wrote it. The cell must also be identical.

Core sequence · step 0

Convergence tests: ENCUT and k-points

NeedsPOSCAR, POTCAR, a static INCAR
RunSeries of single-point runs
ProducesENCUT and k-mesh you can defend in a paper

The total energy itself is never “converged”; what converges is the difference between structures and the derived quantities. Test on the unrelaxed structure with static runs, and pick the smallest setting at which the energy changes by less than 1 meV/atom from the next step up. For stress-based quantities (elastic, EOS) also watch the pressure.

Rules of thumb
  • Insulators converge with coarse meshes (resolution 0.04); metals need 0.02 or finer, plus a smearing test.
  • Use Gamma-centred meshes for hexagonal and trigonal cells.
  • Convergence carries over: a supercell N× larger needs ~N× fewer k-points per direction.
  • Report both the cutoff and the k-mesh (or resolution) in your methods section.

Core sequence · step 1

Structural relaxation

NeedsPOSCAR from CIF, POTCAR, KPOINTS (102, 0.03–0.04), INCAR (101 → SR, + MG)
RunIBRION=2, ISIF=3, repeat from CONTCAR
ProducesCONTCAR (equilibrium cell), WAVECAR, CHGCAR

Every later property is evaluated at this geometry, so errors here propagate everywhere. Experimental lattice constants are not the DFT minimum; PBE typically overestimates them by 1–2%, and using the experimental cell leaves residual stress that spoils elastic and phonon results.

Key parameters and why

TagSettingReason
ENCUT1.3 × ENMAXCell changes alter the number of plane waves at fixed cutoff; the 30% margin keeps the Pulay stress small.
ISIF3Full equilibrium. Use 2 for slabs/defects (cell fixed) and 4 for fixed-volume E–V points.
EDIFFG−0.005 or −0.001 eV/ÅForce criterion: stops when every force is below |EDIFFG| (VASP wiki). −0.001 also suits elastic and phonon work.
EDIFF1E-6 (1E-7–1E-8 with EDIFFG = −0.001)Forces are only as accurate as the SCF; a tight force criterion needs a tight EDIFF.
IBRION2 → 1CG is robust far from the minimum; RMM-DIIS (1) is faster close to it but can diverge from a bad start.

Reading the result

  • Compare lattice constants with experiment: PBE overestimates by ~1–2%, LDA underestimates by ~1–2%, PBEsol and r2SCAN sit closer. Deviations above ~3% suggest wrong magnetic state, missing vdW (layered materials) or wrong POTCAR.
  • Check symmetry is preserved: compare space groups of POSCAR.0 and CONTCAR (VASPkit 601 on POSCAR, 608 on the relaxed structure, or phonopy --symmetry -c CONTCAR).
  • Check moments: grep "mag=" OSZICAR | tail -1 and the magnetization (x) table in OUTCAR.

Core sequence · step 2 (output)

Total and projected density of states

NeedsThe SCF run of step 2 with LORBIT = 11
RunNo extra VASP run: VASPkit reads DOSCAR
ProducesTDOS.dat, PDOS_<El>.dat

With LORBIT = 11 the SCF writes the total and the site- and orbital-projected DOS into DOSCAR. NEDOS = 3001 gives a fine energy grid; the default 301 points is too coarse for clean PDOS. For a smoother DOS, use a denser k-mesh in the SCF (VASPkit 102 with a smaller value, e.g. 0.02).

Interpreting DOS and PDOS

  • VASPkit shifts energies so EF = 0. In an insulator VASP places EF near the valence band maximum, so the gap appears just above 0.
  • Gap. DOS gaps are blurred by Gaussian broadening (SIGMA); take the number from 911 or the band structure.
  • Metallic, half-metallic, semiconducting. Finite DOS at EF in both spin channels means metal; finite in one and gapped in the other means half-metal.
  • Bonding character. Overlapping PDOS peaks of two species in the same energy range (e.g. TM-d with O-p) indicate hybridization; well-separated peaks indicate ionic character.
  • Band edges. The species/orbital dominating the VBM and CBM tells you which states govern absorption and doping.

Band structure

The SCF density must come from a uniform k-mesh covering the whole Brillouin zone. The VASP wiki states that the line-mode mesh “is not suitable for self-consistent calculations”, because points along a path do not sample the zone. So the KPATH.in points are evaluated with the density converged on the uniform mesh. The wiki documents two ways to do that.

Common start

  1. New folder; copy the relaxed POSCAR (standardized primitive cell), POTCAR, the uniform-mesh KPOINTS and the SCF INCAR of step 2 (no ICHARG = 11).
  2. printf "303\n" | vaspkit (2D: 302) → KPATH.in, PRIMCELL.vasp, HIGH_SYMMETRY_POINTS. If PRIMCELL.vasp differs from your POSCAR, use it as POSCAR: the path is defined for that cell.

Route A: one SCF run with KPOINTS_OPT (VASP 6.3 or newer)

  1. Keep the uniform mesh in KPOINTS; cp KPATH.in KPOINTS_OPT.
  2. Run the SCF without ICHARG = 11. VASP wiki: after SCF convergence, VASP computes the band energies for the k-points of KPOINTS_OPT in the same job.
  3. Analysis: the path eigenvalues are written to vasprun.xml (and vaspout.h5). VASPkit 211 needs EIGENVAL_OPT/PROCAR_OPT, which depend on how VASP was compiled (VASPKIT tutorial, “Single-shot band structure”, VASPkit ≥ 1.3.2).

Route B: KPATH.in as KPOINTS reading the SCF density (VASPkit tutorial INCAR)

  1. After the SCF of the common start has converged, keep its CHGCAR in the folder; cp KPATH.in KPOINTS.
  2. Run with the INCAR below: ICHARG = 11 reads that CHGCAR and keeps it fixed. This is the band INCAR in the VASPKIT tutorial and the procedure on the VASP wiki.
  3. printf "211\n" | vaspkit, then 213 (projected), 911 (gap), 912 (effective mass).

Interpreting the band plot

  • Fermi level: the wiki notes that a Fermi energy computed from path k-points is unreliable. Put the SCF value (grep E-fermi OUTCAR of the SCF) on line 2 of FERMI_ENERGY.in before running 211.
  • Labels: keep the point labels after the coordinates in KPOINTS (KPATH.in has them); otherwise KLABELS shows “Undefined”.
  • Direct vs indirect gap: VBM and CBM at the same k-point means direct; different k-points means indirect.
  • Dispersion: steep bands mean light carriers; flat bands mean localized states and heavy masses.
  • Gap accuracy: PBE underestimates gaps. Use HSE06 or mBJ for quantitative gaps.
Common failure

Jagged bands or a wrong gap usually mean the path eigenvalues were computed self-consistently on the path itself, or from a CHGCAR of another cell or spin setting.

Core sequence · step 5

Optical properties

NeedsRelaxed structure; converged SCF (EDIFF 1E-6 → 1E-8) for NBANDS reference and WAVECAR
RunLOPTICS=.TRUE., NBANDS ≈ 3× default, dense k-mesh
Producesε1(ω), ε2(ω) in vasprun.xml / OUTCAR → 711

VASP computes the imaginary part ε2(ω) from transitions between occupied and empty states, and obtains ε1(ω) by a Kramers–Kronig transform. Transitions need empty bands, which is why NBANDS is raised well above the default. This is the independent-particle picture: no excitons, no local-field effects.

Sequence

  1. Static SCF with tight convergence (EDIFF = 1E-8 is ideal for smooth spectra).
  2. Read the default band count: grep NBANDS OUTCAR.
  3. Set NBANDS ≈ 3× that, rounded up to a multiple of the MPI ranks (script below).
  4. 101 → OP, then edit: NBANDS, LOPTICS, CSHIFT, NEDOS, ISPIN/MAGMOM. Use a denser k-mesh than the SCF (0.02 or finer).
  5. Run, then printf "711\n1\n" | vaspkit (1 = eV; 2 = nm; 3 = THz). It reads ε(ω) straight from vasprun.xml. VASPkit warns that 711 is not suitable for low-dimensional materials, where the vacuum dilutes ε.

Quantities derived by 711

|ε| = √(ε₁² + ε₂²) n(ω) = √[(|ε| + ε₁)/2] refractive index k(ω) = √[(|ε| − ε₁)/2] extinction coefficient α(ω) = 2ωk/c = √2 (ω/c) √(|ε| − ε₁) absorption coefficient (cm⁻¹) R(ω) = [(n − 1)² + k²] / [(n + 1)² + k²] normal-incidence reflectivity L(ω) = ε₂ / (ε₁² + ε₂²) energy-loss function (plasmon peaks) σ(ω) = ωε₀ε₂ optical conductivity (real part)

Interpretation

  • Absorption onset ≈ optical gap. If it sits at the PBE gap, it is underestimated: apply a scissor shift (rigidly shift ε2 by Δ = Eg(HSE or exp.) − Eg(PBE), then redo Kramers–Kronig) or run optics with HSE/mBJ. CSHIFT is broadening, not a scissor.
  • ε1(0) is the electronic (high-frequency) dielectric constant ε∞, and n(0) = √ε1(0). Cross-check with LEPSILON (which includes local-field effects).
  • Peaks in ε2 map to interband transitions; assign them using PDOS (e.g. O-2p → TM-3d).
  • Is the band-edge transition allowed? A direct gap can still absorb weakly if the transition is dipole-forbidden. VASPkit 713 computes the transition dipole moment between two bands (e.g. VBM and CBM index) along the band path; run the band calculation with LWAVE = .TRUE..
  • Anisotropy: non-cubic crystals have different xx, yy, zz components. Report them separately or state that you averaged.
  • Metals lack the intraband Drude term in LOPTICS; low-energy spectra of metals are incomplete.
  • Converge NBANDS: raise it until spectra up to your plotted energy stop changing.

Lattice & response

Elastic constants and mechanical properties

NeedsStructure re-relaxed at the elastic run’s ENCUT, residual pressure ≈ 0
RunIBRION=6, ISIF=3, NFREE=4, POTIM=0.015
Produces“TOTAL ELASTIC MODULI” in OUTCAR → 203

With IBRION = 6 and ISIF ≥ 3, VASP applies ± strains to the lattice (six independent strain components) and also displaces the ions, then computes the stress response. The result is the clamped-ion elastic tensor plus the correction from internal ionic relaxation; the sum is printed as TOTAL ELASTIC MODULI. Stress is very sensitive to the basis, so a high cutoff and a fully relaxed cell are essential.

Before you run
  • Relax with exactly this ENCUT, PREC and k-mesh. Then grep "external pressure" OUTCAR | tail -1 should be within about ±1 kB.
  • Use a denser k-mesh than for the relaxation (metals especially); Cij converge slowly with k-points.
  • Use the conventional cell when its axes align with the crystal axes you want Cij in (e.g. cubic), so that VASPkit’s symmetry-specific analysis applies cleanly.
Ordering trap

OUTCAR orders rows and columns as XX YY ZZ XY YZ ZX; Voigt notation is 11 22 33 23 13 12 (YZ ZX XY). VASP’s 4th, 5th, 6th entries map to Voigt 6, 4, 5. VASPkit 203 converts this for you; do it yourself if you parse OUTCAR directly.

Energy–volume curve and equation of state

An E–V curve gives the equilibrium volume and bulk modulus independently of the stress tensor, so it is free of Pulay stress at fixed cutoff. It is also how you compare polymorphs or magnetic states over a range of volumes, and how you get transition pressures.

Lattice & response

Phonons and vibrational properties

NeedsTightly relaxed structure (EDIFFG ≈ −0.001, EDIFF 1E-8)
RunPhonopy finite displacements in a supercell, or DFPT (IBRION=8)
ProducesPhonon dispersion, phonon DOS, free energy, heat capacity, entropy

Phonons test dynamical stability (no imaginary modes means the structure is a local minimum) and give vibrational thermodynamics. The force constants come from forces on atoms when one atom is displaced; a supercell is needed so that a displaced atom does not interact with its own periodic images.

Route A: phonopy with finite displacements (recommended)

  1. Re-relax tightly. EDIFF = 1E-8, EDIFFG = −0.001. Residual forces show up as spurious imaginary modes.
  2. Generate displacements: phonopy -d --dim 2 2 2 -c POSCAR. Writes SPOSCAR (perfect supercell), POSCAR-001…, phonopy_disp.yaml. Choose DIM so each supercell edge is ≳ 10 Å.
  3. Run one static VASP job per displacement with the INCAR below and a k-mesh reduced in proportion to the supercell.
  4. Collect forces: phonopy -f disp-*/vasprun.xml → FORCE_SETS.
  5. Dispersion and DOS with band.conf and mesh.conf, then thermal properties.

Route B: DFPT force constants (IBRION = 8)

Run one VASP job on the perfect supercell (cp SPOSCAR POSCAR) with IBRION = 8, EDIFF = 1E-8, NCORE removed. Then phonopy --fc vasprun.xml writes FORCE_CONSTANTS; add FORCE_CONSTANTS = READ to band.conf and mesh.conf. DFPT is one job instead of many, but it does not support every functional (no hybrids, limited +U support) and scales poorly for large supercells.

Polar materials: LO–TO splitting

In ionic insulators the long-range dipole field splits longitudinal and transverse optical modes at Γ. Without a correction the Γ-point optical branches are wrong. Compute ε∞ and Born charges in the unit cell (next section), then phonopy-vasp-born vasprun.xml > BORN and set NAC = .TRUE..

Γ-point modes only

For IR/Raman assignment you only need Γ frequencies: run IBRION = 5–8 on the unit cell (101 → FQ). OUTCAR lists each mode as f (real) or f/i (imaginary) in THz, 2πTHz, cm⁻¹ and meV. Three near-zero modes are the acoustic translations.

Interpreting phonons

  • No imaginary branches: dynamically stable at 0 K.
  • Small imaginary acoustic dip near Γ (a few cm⁻¹): numerical noise. Tighten EDIFF, add ADDGRID, increase ENCUT/k-mesh or supercell, re-relax tighter.
  • Large imaginary modes at a zone-boundary point: genuine instability. Displace atoms along that eigenvector in the matching supercell and re-relax to find the lower-symmetry phase.
  • Gap between acoustic and optical branches follows from mass contrast; flat, low-lying optical modes (rattlers) suppress thermal conductivity.
  • Thermal properties: heat capacity CV approaches 3NkB per cell at high T (Dulong–Petit); vibrational free energy Fvib(T) adds to EDFT for finite-temperature phase stability. Quasi-harmonic (phonopy-qha) adds thermal expansion.

Lattice & response

Dielectric tensor and Born effective charges

NeedsRelaxed unit cell; insulator or semiconductor
RunLEPSILON=.TRUE., IBRION=8 (or LCALCEPS with IBRION=6)
Producesε∞, ionic ε, ε₀, Born effective charges Z*, piezoelectric tensor

The Born effective charge Z*κ,αβ is the polarization change in direction α when atom κ moves in direction β. It measures dynamical charge, which can greatly exceed the nominal ionic charge in materials with strong covalent/ferroelectric character. ε∞ is the electronic screening; adding the ionic contribution gives the static ε0.

  • Acoustic sum rule: Σκ Z*κ should be ≈ 0 for each tensor component. A sum above ~0.1 means the k-mesh or EDIFF is too loose.
  • Anomalous Z* (e.g. Ti ≈ +7 in BaTiO₃ vs nominal +4) signals strong p–d hybridization and proximity to a ferroelectric instability.
  • ε0 = ε∞ + εion. Compare ε∞ with ε1(0) from LOPTICS; LEPSILON includes local-field effects and is usually slightly smaller.
  • ε, Z* and polarization are ill-defined in metals; do not run this on a metallic state.

Charge & spin

Bader charge analysis

NeedsRelaxed structure; Henkelman bader code and chgsum.pl (VTST scripts)
RunStatic run with LAECHG=.TRUE.
ProducesACF.dat: electrons per atom → net atomic charges

Bader partitions space along zero-flux surfaces of the charge density and integrates the electrons in each atom’s basin. PAW CHGCAR files contain only the pseudo valence density, which has no maxima at the nuclei, so the partition is done on the all-electron reference (core + valence) and the valence charge is integrated inside those basins.

  • Sign: positive net charge means electrons lost (cation-like). Bader charges are always smaller than formal oxidation states (e.g. O ≈ −1.0 to −1.3 in oxides); compare trends, not absolute values.
  • Check: the total of the CHARGE column equals the total valence electrons; vacuum charge at the bottom of ACF.dat should be ≈ 0 for bulk.
  • Grid convergence: repeat with a finer FFT grid; charges should change by < 0.01 e.
  • Charge transfer at interfaces/adsorbates: sum the Bader charges of each fragment and compare with the isolated fragments; combine with charge-density difference plots (Δρ = ρAB − ρA − ρB, same grid and cell).

Charge & spin

Magnetic properties and ground-state search

NeedsRelaxed structure; supercell that can hold the AFM orders you want
RunNM, FM and several AFM configurations, each relaxed, same cell and settings
ProducesGround-state order, moments, exchange energies, MAE

A spin-polarized calculation finds the nearest local minimum to the starting MAGMOM, not necessarily the ground state. You find the ground state by explicitly computing all plausible orders and comparing their energies per formula unit.

Configuration comparison

  1. Build a supercell that accommodates each order (e.g. doubling along c for layered A-type AFM, √2×√2 or 2×2×2 for checkerboard G-type). Use the same supercell for every configuration, including FM and NM, so k-point and basis errors cancel.
  2. Set MAGMOM per configuration (below) and relax each one (ISIF=3), since magnetic order changes the volume.
  3. Run a static SCF for each; compare energy without entropy per formula unit.
  4. Check that each run kept its intended pattern: if an AFM start ended FM, that configuration is unstable or the start was poor.

Interpretation

  • ΔE = EAFM − EFM per formula unit: positive → FM ground state; negative → AFM. Differences below a few meV/f.u. are within DFT uncertainty and depend strongly on U.
  • Moments per site are integrated inside PAW spheres and slightly smaller than the formal value (e.g. high-spin Fe³⁺ ≈ 4.2–4.3 μB vs 5 μB). The total cell moment is integer for half-metals and insulators.
  • Exchange constants: map the energies of three or more configurations onto a Heisenberg model E = E₀ − Σ Jij Si·Sj and solve for J₁, J₂… Count bonds carefully per configuration.
  • Mean-field TC estimate: kBTC ≈ (2/3) ΔE per magnetic atom. It overestimates; Monte Carlo on the fitted J is more reliable.
  • Half-metallicity: one spin channel gapped at EF in the spin-resolved DOS, with an integer total moment.

Magnetocrystalline anisotropy (SOC)

  1. Collinear SCF with vasp_std, LMAXMIX = 4 (6 for f), tight EDIFF; keep CHGCAR and WAVECAR.
  2. Non-collinear runs with vasp_ncl: LSORBIT = .TRUE., ICHARG = 11, ISYM = -1, LORBMOM = .TRUE., MAGMOM as 3 components per atom, one run per spin direction (e.g. MAGMOM = 0 0 4 … for [001], 4 0 0 … for [100]).
  3. MAE = E[100] − E[001] (μeV–meV per atom). Converge the k-mesh hard: MAE needs very dense sampling.

Choosing U

  • Literature / database values (above) keep your energies compatible with Materials Project-style phase diagrams.
  • Linear response (Cococcioni–de Gironcoli): compute the response of d-occupation to small potential shifts (LDAUTYPE = 3) and derive U self-consistently for your compound.

Pitfalls
  • Total energies with different U are not comparable. Formation energies mixing +U and plain GGA compounds need a correction scheme (e.g. MP2020).
  • +U creates metastable states: different MAGMOM or starting occupations can converge to different energies. Try several starts and keep the lowest; occupation-matrix control or U-ramping (0 → U in steps, reading WAVECAR) help.
  • LDAUL/LDAUU/LDAUJ need one entry per species, in POSCAR order. A missing entry silently shifts values to the wrong element.
  • Check the d-occupations (LDAUPRINT = 1) and moments make chemical sense for the expected oxidation state.

Beyond PBE

Meta-GGA: SCAN, r2SCAN, mBJ

NeedsPOTCARs carrying kinetic-energy-density data (PBE.52/.54/.64 sets); PBE WAVECAR as a start
RunMETAGGA tag, LASPH, ALGO=All
ProducesBetter structures and energetics (r2SCAN); better gaps (mBJ)

Meta-GGAs add the kinetic-energy density τ to the functional. SCAN satisfies all known exact constraints of a semilocal functional and improves lattice constants, formation energies and intermediate-range bonding over PBE at moderate cost. r2SCAN keeps most of that accuracy with much better numerical stability. mBJ is a model potential designed for band gaps.

  • Band structures with meta-GGA: the safest route is the zero-weight k-point method used for hybrids (251 → SCF with that KPOINTS → 252), since non-self-consistent ICHARG = 11 runs need τ, which is not stored in CHGCAR in older VASP versions.
  • SCAN is sensitive to the integration grid; if energies jump between runs, use r2SCAN.
  • Do not mix meta-GGA and PBE energies in one formation-energy calculation; every reference must use the same functional.

Beyond PBE

Hybrid functionals: HSE06 and PBE0

NeedsPBE-relaxed structure, converged PBE WAVECAR (same k-mesh)
RunLHFCALC, HFSCREEN, ALGO=Damped/All, from WAVECAR
ProducesAccurate gaps, band edges, defect levels; costly

Hybrids replace part of the semilocal exchange with exact (Fock) exchange, reducing self-interaction error. HSE06 screens the long-range part (HFSCREEN = 0.2 Å⁻¹), making it practical for solids. Gaps typically come within ~10–20% of experiment for sp semiconductors, but cost rises 10–100×, mostly with the number of k-points.

Hybrid band structure (no ICHARG = 11)

Exact exchange needs wavefunctions on a uniform mesh, so a frozen-density band run is not possible. Instead, the path points are added to the SCF k-point list with zero weight: they do not contribute to the density but get correct eigenvalues.

  1. PBE SCF on a uniform mesh; keep WAVECAR to start the hybrid run.
  2. 303 for KPATH.in, then 251: give the SCF mesh type and resolution, then the path resolution (0.04–0.06). VASPkit writes a KPOINTS with the weighted irreducible mesh first and the zero-weight path points after it.
  3. HSE run with that KPOINTS (it is one SCF calculation; cost grows with the extra points, so use ~10–20 per segment).
  4. 252 extracts the band structure (253–255 for projected hybrid bands); 911 for the gap.
  • Relaxing with HSE is rarely worth it; PBE (or PBEsol/r2SCAN) geometries plus HSE electronic structure is standard. Say which you used.
  • Optics with HSE: LOPTICS works in the HSE SCF, but it is expensive. A scissor shift of PBE spectra to the HSE gap is a common compromise.
  • If the SCF diverges: converge PBE first, use ALGO = All or Damped with smaller TIME (0.2), and avoid starting from random wavefunctions.

Troubleshooting convergence

First decide which loop is failing. In OSZICAR, the lines starting with DAV: / RMM: are electronic steps; the lines with F= are ionic steps. If each ionic step burns all NELM electronic steps, fix the electronic problem first; ionic convergence cannot happen on unconverged forces.

Electronic (SCF) ladder

Work down the list; stop at the first rung that fixes it.

  1. Check the input. Atoms too close, POSCAR/POTCAR species order mismatch, MAGMOM count wrong, unreasonable starting moment.
  2. Progressive EDIFF. Run with EDIFF = 1E-4 until stable, then restart from the result with ISTART = 1, ICHARG = 1 and EDIFF = 1E-5, then 1E-6 (and 1E-8 for response). Each stage starts closer to the solution, so the tight stage converges in a few steps instead of wandering from random wavefunctions. Your “converge repeatedly” step is this ladder.
  3. Change the algorithm. ALGO = Normal (most robust Davidson) → All → Damped with TIME = 0.4. Avoid Fast/VeryFast for magnetic or +U systems.
  4. Damp the mixing. AMIX = 0.1, BMIX = 0.0001, AMIX_MAG = 0.4, BMIX_MAG = 0.0001 (linear mixing). For charge sloshing in metals/slabs reduce AMIX and BMIX gradually.
  5. More steps and warm-up. NELM = 200–300, NELMDL = -12.
  6. Smearing. Temporarily larger SIGMA (0.1–0.2) for metals or near-degenerate states, then reduce and restart from CHGCAR.
  7. Spin strategy. Converge non-spin-polarized first, then restart spin-polarized from that CHGCAR (ICHARG = 1) with MAGMOM; or fix the moment with NUPDOWN, converge, then release it.
  8. DFT+U / hybrids. Converge plain PBE first and restart from its WAVECAR; ramp U in steps; set LMAXMIX = 4/6.
  9. Numerics. Change NCORE/KPAR or the core count; LREAL = .FALSE.; PREC = Accurate; small odd behaviour can come from parallel round-off.

Ionic (relaxation) ladder

  1. Relax in stages. ISIF = 2 (ions only) first, then ISIF = 3 from that CONTCAR. Large initial stress plus bad positions is the usual cause of runaway relaxations.
  2. Loose then tight EDIFFG. Start with an energy criterion (EDIFFG = 1E-3) or −0.05 eV/Å, then tighten to −0.005 → −0.001. Keep EDIFF at least 10× smaller than any energy EDIFFG; with force criteria use EDIFF ≤ 1E-6.
  3. Step size. Reduce POTIM (0.1–0.2) if energy oscillates or ZBRENT complains.
  4. Switch optimizer. IBRION = 2 (CG) far from minimum; 1 (RMM-DIIS) close to it; 3 (damped MD, POTIM ≈ 0.1) for very rough landscapes or soft modes.
  5. Restart cleanly. cp CONTCAR POSCAR; delete WAVECAR/CHGCAR if the cell changed a lot. Re-run until converged in 1–3 steps (removes Pulay stress).
  6. Check symmetry. A symmetric starting point is a saddle point if the true minimum breaks symmetry. Rattle positions slightly (0.01–0.05 Å) or set ISYM = 0 to let it escape.
  7. Fix what should not move. Selective dynamics for slab bottom layers; ISIF = 2 for defects in a fixed host cell.
Signs of a good calculation
  • Every ionic step converged electronically in fewer than NELM steps.
  • “reached required accuracy” in OUTCAR; final forces below |EDIFFG|; pressure within ±1–2 kB.
  • Moments and symmetry are what you intended, or the change is understood.
  • Smearing entropy (EENTRO) below ~1 meV/atom.
