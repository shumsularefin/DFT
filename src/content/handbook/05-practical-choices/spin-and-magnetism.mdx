<Why>

Electrons carry spin. In many closed-shell materials the up and down electrons are equally numerous everywhere, so treating both spins together is accurate and half the cost. In magnetic materials (iron, transition-metal oxides, rare-earth compounds) and in radicals the two spin densities differ, and forcing them to be equal gives the wrong energy and the wrong structure. Turning spin on is a decision you make in every run, and the starting guess for each atom matters because the calculation can settle in the wrong magnetic state <Cite id="S-042" />.

</Why>

<Intuition>

With spin polarization off (`ISPIN = 1`), every orbital holds two electrons, one up and one down. With it on (`ISPIN = 2`), VASP keeps separate up and down orbitals, so the two spin densities can differ. The difference is the magnetization density <Cite id="S-059" />.

<Level min="intermediate">

VASP includes the `MAGMOM` pattern in its symmetry analysis, so an antiferromagnetic arrangement lowers the symmetry automatically; no separate `POTCAR` species is needed for the up and down sites (VASP wiki page MAGMOM, recorded as Q-040). You can build ready-to-run inputs for all standard orderings in one common supercell with the [Magnetic configuration tool](/tools/magnetic/).

</Level>

</Intuition>

<TheMath>

Write the up and down densities as $n_\uparrow(\mathbf r)$ and $n_\downarrow(\mathbf r)$. The total density is $n(\mathbf r) = n_\uparrow(\mathbf r) + n_\downarrow(\mathbf r)$ and the magnetization density is $m(\mathbf r) = n_\uparrow(\mathbf r) - n_\downarrow(\mathbf r)$ (in units of the Bohr magneton, $\mu_B$, when each electron counts as one) <Cite id="S-059" />. The total moment of a cell is the integral of $m(\mathbf r)$ over the cell volume. In an antiferromagnet the site moments cancel in the sum, so the net moment is zero while each magnetic site still carries a local moment.

</TheMath>

<InVasp>

<TagVisual tag="ISPIN" />

- `ISPIN = 2` turns on collinear spin polarization (default 1). It roughly doubles the time and memory <Cite id="S-042" />.
- `MAGMOM` takes one value per atom, in `POSCAR` order, in $\mu_B$. The shorthand `4*3.0` means four atoms at 3.0. The count must equal the number of atoms <Cite id="S-042" />.
- The author's rule for the starting moment of 3d magnetic ions is 3 to 5 $\mu_B$; if it is too small, the moment can collapse to zero <Cite id="S-042" />.
- `LORBIT = 11` writes projected densities and the site-resolved moments in `OUTCAR`. `OSZICAR` shows the total moment as `mag` <Cite id="S-041" />.
- Keep `ISPIN`, `MAGMOM` and `LMAXMIX` identical between an SCF run and any `ICHARG = 11` run that follows it <Cite id="S-042" />.

</InVasp>

<WhatChanges>

| If you change...           | ...in the physical picture       | ...in VASP                                                         |
| -------------------------- | -------------------------------- | ------------------------------------------------------------------ |
| `ISPIN = 1` to `ISPIN = 2` | Up and down densities can differ | Separate spin channels; roughly double the memory and run time     |
| FM to AFM arrangement      | Neighbour arrows point opposite  | Different state with its own energy; compare in the same supercell |
| A smaller starting moment  | Weak initial spin imbalance      | Risk of collapsing to a non-magnetic solution                      |
| Leave out one `MAGMOM`     | Missing site assignment          | Count mismatch error against the atom count in `POSCAR`            |

Why turn spin on: magnetic systems need separate up and down densities. Why this starting moment: large enough not to collapse. What happens if you get it wrong: a non-magnetic state reported for a magnetic material.

</WhatChanges>

<Mistakes>

<Callout variant="mistake" title="Starting from zero or from the wrong arrangement">

A run started with zero moment can stay non-magnetic, and a ferromagnetic start will not find an antiferromagnetic state. Test the arrangements you care about.

</Callout>

<Callout variant="mistake" title="Comparing energies from different cells">

Energies of different magnetic orderings are comparable only in the same cell with the same settings and k-point mesh.

</Callout>

<Callout variant="mistake" title="Treating MAGMOM as a fixed result">

`MAGMOM` only seeds the initial density. Always inspect the final moments in `OSZICAR` and `OUTCAR`.

</Callout>

</Mistakes>
