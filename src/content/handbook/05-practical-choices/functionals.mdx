<Why>

Kohn-Sham DFT is exact in principle, but the exchange-correlation functional is not known, so every calculation uses an approximation. The choice sets which properties come out well (lattice constants, band gaps, magnetic energies) and how long the run takes. A wrong match, such as a plain GGA for a band gap, is a common reason a calculation disagrees with experiment even though everything else is converged <Cite id="S-042" />.

</Why>

<Intuition>

Think of a ladder. Each rung uses more information about the electrons, and costs more <Cite id="S-046" />:

1. **LDA** uses only the density at each point.
2. **GGA** (PBE is the common one <Cite id="S-013" />) also uses how fast the density changes.
3. **Meta-GGA** (SCAN, r2SCAN <Cite id="S-026" />) also uses the kinetic-energy density of the orbitals.
4. **Hybrid** (HSE06, PBE0 <Cite id="S-025" />) mixes in a fraction of exact exchange. It often improves band gaps and is much more expensive.
5. **Beyond** (using the empty orbitals as well) is the most expensive rung.

Higher is not automatically better for every property. The lab lets you pick a rung and shows what it adds, what it costs and which tags switch it on. The only numbers on the page come from the author's handbook: compared with experiment, PBE tends to overestimate lattice constants by about 1 to 2 percent and LDA to underestimate them by about 1 to 2 percent, with PBEsol and r2SCAN closer. Deviations above about 3 percent suggest a wrong magnetic state, missing van der Waals or a wrong POTCAR <Cite id="S-042" />. These are rules of thumb.

<Level min="intermediate">

The author's protocol works at the PBE level and treats the rest as a change of functional followed by repeating the relevant calculation: DFT+U (`LDAU`), meta-GGA (`METAGGA`: r2SCAN, SCAN or mBJ) or HSE06 (`LHFCALC`) <Cite id="S-042" />. The modified Becke-Johnson (mBJ) potential is aimed at band gaps of semiconductors and insulators <Cite id="S-027" />.

</Level>

</Intuition>

<Lab id="functional-ladder" title="Jacob's ladder of functionals" />

<TheMath>

The exchange-correlation energy is a functional of the density, $E_{xc}[n]$. The rungs differ in what it may depend on:

| Rung     | Depends on                                                   |
| -------- | ------------------------------------------------------------ |
| LDA      | $n(\mathbf r)$                                               |
| GGA      | $n(\mathbf r)$ and $\lvert\nabla n(\mathbf r)\rvert$         |
| Meta-GGA | adds the kinetic-energy density $\tau(\mathbf r)$            |
| Hybrid   | adds a fraction of exact exchange from the occupied orbitals |

A hybrid replaces part of the semilocal exchange by Hartree-Fock exchange, $E_x = E_x^{\text{semilocal}} + a\,(E_x^{\text{HF}} - E_x^{\text{semilocal}})$ with a fraction $a$ (0.25 in the common hybrids). HSE06 applies the exact part only at short range <Cite id="S-025" />. This is the structure only; no numerical constants of the functionals are reproduced here <Cite id="S-049" />.

</TheMath>

<InVasp>

- LDA and GGA are set by the `POTCAR` family: PBE files carry the PBE functional (PE).
- Meta-GGA: `METAGGA = R2SCAN` (or `SCAN`, `MBJ`). Remove any `GGA` tag. It needs `LASPH = .TRUE.` and a `POTCAR` that supports it; `LMIXTAU = .TRUE.` can stabilise the SCF <Cite id="S-042" />.
- Hybrid: `LHFCALC = .TRUE.`, `HFSCREEN = 0.2` with `AEXX = 0.25` is HSE06; `HFSCREEN = 0` with `AEXX = 0.25` is PBE0. `AEXX` can be tuned to reproduce a known gap; report it if you do <Cite id="S-042" />.
- Hybrid runs are far more expensive. `PRECFOCK = Fast` and `NKRED = 2` cut the cost several-fold; check that the gap changes by less than about 0.05 eV. `ICHARG = 11` does not work with hybrids <Cite id="S-042" />.
- Changing the functional means repeating the calculations that depend on it, with the same `ENCUT`, `ISPIN`, `MAGMOM`, `LMAXMIX` and any `LDAU` tags <Cite id="S-042" />.
- Defaults for `LHFCALC`, `HFSCREEN` and `METAGGA` are not stated in the handbooks: check the VASP wiki <Cite id="S-019" />.

**Meta-GGA in practice** <Cite id="S-042" />:

- **SCAN or r2SCAN.** SCAN is sensitive to the integration grid: if its energies jump between otherwise identical runs, use r2SCAN, which keeps most of SCAN's accuracy with much better numerical stability. Meta-GGAs also need a higher cutoff than PBE (the handbook's example uses `ENCUT = 600`) and are best started from a converged PBE `WAVECAR`.
- **With van der Waals.** The rVV10 dispersion term is switched on with `LUSE_VDW = .TRUE.`. Its parameter depends on the functional: `BPARAM = 15.7` for SCAN+rVV10 and `11.95` for r2SCAN+rVV10.
- **mBJ gives no total energy.** mBJ is a model potential, not an energy functional, so it gives no total energy and no forces. Use it at a fixed geometry (`NSW = 0`) taken from a PBE relaxation, for the gap only.
- **One functional per comparison.** Do not mix meta-GGA and PBE energies in one formation energy: every reference must use the same functional.

**Band structures with hybrids (and meta-GGA)** <Cite id="S-042" />. Exact exchange needs the wavefunctions on a uniform mesh, so the usual `ICHARG = 11` band run is not possible. Instead the path points are added to the SCF k-point list with **zero weight**: they do not change the density but still get correct eigenvalues.

1. PBE SCF on a uniform mesh; keep its `WAVECAR`. Why: the hybrid run starts from it and converges far more easily.
2. VASPKIT 303 writes `KPATH.in`, then 251 writes a `KPOINTS` with the weighted mesh first and the zero-weight path points after it (path resolution 0.04 to 0.06 for hybrids). Why: one SCF run then gives both the density and the bands.
3. Run the hybrid SCF with that `KPOINTS`. The cost grows with the extra points, so use about 10 to 20 per segment.
4. VASPKIT 252 extracts the bands (253 to 255 for projected bands); 911 gives the gap.

The same route is the safest one for meta-GGA bands, because older VASP versions do not store the kinetic-energy density that an `ICHARG = 11` run would need.

**Optics with HSE.** `LOPTICS` works in the HSE SCF run but is expensive. A common compromise is a PBE spectrum shifted rigidly to the HSE gap (a scissor shift) <Cite id="S-042" />. Relaxing with HSE is rarely worth it: a PBE (or PBEsol, r2SCAN) geometry with HSE electronic structure is standard; say which you used.

</InVasp>

<WhatChanges>

| If you change...   | ...in the lab                   | ...in VASP                                                        |
| ------------------ | ------------------------------- | ----------------------------------------------------------------- |
| Up one rung        | More ingredients, higher cost   | More expensive run; sometimes a better property, never guaranteed |
| PBE to a hybrid    | Adds exact exchange             | `LHFCALC` on, much more time, often a larger gap                  |
| PBE to r2SCAN      | Adds the kinetic-energy density | `METAGGA`, `LASPH`, no `GGA` tag                                  |
| A different `AEXX` | Not shown                       | A different functional from the one you report                    |

Why pick a functional on purpose: it limits the accuracy of the answer no matter how well converged the rest is. Why this value: match the functional to the property. What happens if you get it wrong: gaps and energies that disagree with experiment for a reason no convergence test will find.

</WhatChanges>

<Mistakes>

<Callout variant="mistake" title="Quoting a PBE band gap as if it were the real gap">

Semilocal functionals tend to underestimate gaps. Use a hybrid or mBJ when the gap matters, and say which you used.

</Callout>

<Callout variant="mistake" title="Assuming a higher rung is always better">

The ladder adds ingredients and cost. Whether the answer improves depends on the property and the material.

</Callout>

<Callout variant="mistake" title="Changing the functional but not the inputs that must match">

An `ICHARG = 11` run inherits its physics from the `CHGCAR`: the functional, `ENCUT`, `ISPIN`, `MAGMOM`, `LMAXMIX` and `LDAU` tags must match the run that wrote it <Cite id="S-042" />.

</Callout>

</Mistakes>
