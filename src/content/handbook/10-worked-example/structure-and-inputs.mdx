<Why>

Every number a calculation produces is a property of its inputs. The cell decides which distortions are possible, the potentials decide which electrons are treated, and the starting moments decide which magnetic state the run can reach. For $\mathrm{LaCuO}_3$ each of these choices is a real decision, so this page writes out all four input files in full and gives the reason for every line <Cite id="S-042" />.

</Why>

<Intuition>

**The cell: start simple, on purpose.** The fully oxidized compound is reported as rhombohedral <Cite id="S-096" />, which means tilted octahedra and a cell of two formula units. The worked example still starts from the ideal cubic five-atom cell, for two reasons. It is the cheapest cell, so the convergence tests and the spin tests on the next pages run quickly. And it is the reference against which the tilted structure is measured: the energy gained by tilting is the difference between the two. The tilted cell comes in on the relaxation page.

**The lattice parameter is a starting guess.** This page uses no measured lattice parameter, because none is quoted here from a source we could check. Instead, the starting edge comes from the same radii as the tolerance factor: the ideal cubic edge along Cu-O-Cu is $a = 2(r_\mathrm{Cu} + r_\mathrm{O})$ with Shannon's radii <Cite id="S-001" /> <Cite id="S-002" />, which gives 3.88 Å. It is labelled as a guess in the file, and the relaxation will move it.

**The potentials.** VASP's recommended PAW set for these elements is `La`, `Cu_pv` and `O` <Cite id="S-019" />. `Cu_pv` treats the copper 3p shell as valence as well as 3d and 4s. Lanthanum's 4f shell is empty in $\mathrm{La}^{3+}$, so the standard `La` potential is fine; for Pr to Lu the recommended `_3` potentials freeze the 4f electrons in the core.

**Spin: why there are three starts.** In an octahedron the five $d$ levels split into three lower $t_{2g}$ levels and two higher $e_g$ levels, the <Term id="crystal-field-splitting">crystal-field splitting</Term> <Cite id="S-100" />. Eight $d$ electrons fill the $t_{2g}$ levels (six) and put two in the $e_g$ pair. In a regular octahedron the two $e_g$ orbitals have the same energy, so Hund's rule puts one electron in each with parallel spins: spin $S = 1$, a nominal moment of $2\,\mu_B$. A spin-zero ("low-spin") $d^8$ state needs the two $e_g$ levels split apart, as in an elongated or square-planar site <Cite id="S-100" />, which the cubic cell does not allow. On top of that, strong Cu-O mixing <Cite id="S-098" /> <Cite id="S-099" /> may wash the local moment out entirely in a metal. Because nobody can tell in advance which of these wins in DFT, you run three starts and compare energies:

- non-magnetic (`ISPIN = 1`),
- ferromagnetic from a moment above the nominal value (`MAGMOM` of 3 on Cu),
- ferromagnetic from a small moment (`MAGMOM` of 1 on Cu), to see whether a low-moment solution exists.

An antiferromagnetic start needs two copper atoms; it comes with the doubled cell.

**DFT+U: whether, and how much.** The Materials Project's $U$ list for oxides covers Co, Cr, Fe, Mn, Mo, Ni, V and W, and not Cu <Cite id="S-042" /> <Cite id="S-034" />, so Materials-Project-compatible energies for copper oxides use plain GGA on Cu. For the physics of $\mathrm{Cu}^{3+}$ you may still want a $U$, but there is no single right value to copy. The honest routes are: run plain PBE as the baseline, then scan $U$ and report how the conclusions change, or compute $U$ by linear response for this compound <Cite id="S-042" /> <Cite id="S-095" />. Keep in mind that a $U$ acts on Cu 3d only, while in a negative charge-transfer compound much of the hole sits on oxygen <Cite id="S-099" />.

</Intuition>

<TheMath>

**Starting lattice parameter.** From the $B$-site contact and from the $A$-site contact <Cite id="S-002" />:

$$a_B = 2\,(r_\mathrm{Cu} + r_\mathrm{O}) = 2\,(0.54 + 1.40)\ \text{Å} = 3.88\ \text{Å}, \qquad a_A = \sqrt{2}\,(r_\mathrm{La} + r_\mathrm{O}) \approx 3.90\ \text{Å},$$

using $r_\mathrm{La} = 1.36$ Å (CN 12) <Cite id="S-001" />. Their ratio is the tolerance factor of the previous page. The two estimates differ by about half a percent, which is why the cubic cell is a sensible starting point for La; both are geometry, not predictions.

**Electron count.** The valence electrons per formula unit follow from the POTCAR valences: 11 for `La`, 17 for `Cu_pv` and 6 for each `O`, so $11 + 17 + 3 \times 6 = 46$ <Cite id="S-019" />. VASP reads the counts from the POTCAR files itself; you check the `NELECT` line in `OUTCAR` against this sum.

**The DFT+U energy.** In Dudarev's form (`LDAUTYPE = 2`) only $U_\mathrm{eff} = U - J$ matters, and the correction for each site and spin is <Cite id="S-014" />

$$E_U = \frac{U - J}{2}\sum_{\sigma}\mathrm{Tr}\left[\mathbf n^{\sigma}\left(1 - \mathbf n^{\sigma}\right)\right],$$

where $\mathbf n^\sigma$ is the occupation matrix of the Cu 3d orbitals for spin $\sigma$. The term is zero when every orbital is either full or empty and positive for fractional occupations, so it pushes the $d$ orbitals towards integer filling.

<Level min="intermediate">

**Why LMAXMIX = 4.** VASP keeps the one-centre densities inside each PAW sphere only up to angular momentum `LMAXMIX` when it mixes densities and when it writes `CHGCAR`. The default of 2 drops the $l = 3$ and $l = 4$ components that products of two $d$ orbitals contribute, which matters for DFT+U and for any `ICHARG = 11` run that reads the charge density back. Set 4 for $d$ elements, 6 for $f$ elements <Cite id="S-042" /> (VASP wiki page LMAXMIX <Cite id="S-019" />). Lanthanum sits in the $f$ block of the periodic table, so the site's INCAR check suggests 6 once `LDAU` is on; here $U$ acts only on Cu $3d$ and the La $4f$ shell is empty, so this page keeps 4. Setting 6 costs little, and it is the value to use from Ce onwards or whenever $U$ acts on $f$ states.

**Why ENCUT = 1.3 times ENMAX.** A variable-cell relaxation follows the stress, and at a fixed cutoff the stress carries the Pulay error <Cite id="S-040" />. The author's protocol sets `ENCUT` to 1.3 times the largest `ENMAX` among the POTCARs <Cite id="S-042" />. Read the values with `grep ENMAX POTCAR`; in oxides the standard O potential usually has the largest. The INCAR below uses 520, which is 1.3 times 400; recompute it from your own POTCAR.

</Level>

<Level min="pro">

Dudarev's $E_U$ is not the same functional for different $U$, so total energies with different $U$ cannot be subtracted, and a phase diagram that mixes $U$ and no-$U$ compounds needs a correction scheme <Cite id="S-042" />. DFT+U also has metastable solutions: different starting moments or occupations can converge to different energies. Check the occupation matrices (`LDAUPRINT = 1`) and keep the lowest-energy solution <Cite id="S-042" />.

</Level>

</TheMath>

For the other two starts, change only the spin lines: `ISPIN = 1` and no `MAGMOM` for the non-magnetic run, `MAGMOM = 0 1 3*0` for the low-moment start. For a DFT+U run, add the block below, one entry per species in POSCAR order (La, Cu, O). The value 4 is one point of a scan, not a recommendation.

<WhatChanges>

| If you change...               | ...what happens                                                          | Why                                                        |
| ------------------------------ | ------------------------------------------------------------------------ | ---------------------------------------------------------- |
| `ISPIN = 2` to `ISPIN = 1`     | No moment can form                                                       | Both spin channels are forced equal                        |
| Cu `MAGMOM` 3 to 1             | The run may land on a different, lower-moment solution                   | Spin-polarized runs find the nearest local minimum         |
| `LDAUU` on Cu from 0 upwards   | The d occupations become more integer; energies are no longer comparable | $E_U$ changes the functional itself                        |
| `LMAXMIX` left at the default  | A later `ICHARG = 11` run starts from a density missing its d part       | The default keeps only $l \le 2$ in the mixer and `CHGCAR` |
| Cubic cell to the doubled cell | Tilts and antiferromagnetic order become possible                        | The 5-atom cell has one Cu and no room for rotations       |
| `ENCUT` below 1.3 times ENMAX  | The stress, and therefore the relaxed volume, is biased                  | Pulay stress at fixed cutoff                               |

Why each choice: the cell sets what can happen, the potentials set which electrons count, the spin starts set where the run can go. Why these values: they follow the author's protocol and VASP's recommended potentials. What happens if you skip the spin starts: you get one local minimum and no way to know whether it is the lowest.

</WhatChanges>

<Mistakes>

<Callout variant="mistake" title="A MAGMOM list that does not follow the POSCAR order">

`MAGMOM = 3 0 3*0` puts the moment on La. Fix: write one value per atom in the POSCAR order (La, Cu, O, O, O) and read it back against the species line before you submit.

</Callout>

<Callout variant="mistake" title="LDAU tags in the wrong species order">

`LDAUL`, `LDAUU` and `LDAUJ` take one entry per species in POSCAR order. A shifted list silently puts $U$ on the wrong element <Cite id="S-042" />. Fix: write them under the species line and check `LDAUPRINT` output for Cu.

</Callout>

<Callout variant="mistake" title="Comparing energies made with different U">

A run at one $U$ and a run at another describe different functionals, so their energy difference means nothing <Cite id="S-042" />. Fix: compare magnetic states and structures at the same $U$, and scan $U$ only to see whether conclusions change.

</Callout>

<Callout variant="mistake" title="Mixing Cu and Cu_pv between runs">

Energies from different POTCAR variants of the same element do not subtract. Fix: choose `Cu_pv` once and use it in every run of the project, including the reference compounds.

</Callout>

<Callout variant="mistake" title="Using the starting guess as a result">

The 3.88 Å in the POSCAR comes from ionic radii. Fix: quote only the relaxed lattice parameter from a converged run, and say which functional and $U$ produced it.

</Callout>

</Mistakes>
